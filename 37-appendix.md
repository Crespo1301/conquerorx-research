# Appendix: Quick Access Menu Icons

Final CHM section. From `Conqueror-2-533.html` and
`Conqueror-2-534.html`. One sub-section: **Quick Access Menu Icons.**

Path in CHM: **APPENDIX > Quick Access Menu Icons.**

## What it is

A visual reference sheet: 13 icon images used across the Conqueror
Quick Access Menu and main-menu surfaces. The CHM page ships as
image-only content with no captions, labels, or accompanying text
identifying each icon.

## Why this doc is short

The Appendix in the shipped English CHM is content-thin. Both
`Conqueror-2-533.html` (parent) and `Conqueror-2-534.html` (only
sub-page) render to essentially empty plain-text extractions. The
substance is the 13 icon images themselves:

1. Open the raw source at `extracted-strings/chm-en/Conqueror-2-534.html`

   `extracted-strings/chm-en/images/`).
2. Cross-check against the live Quick Access Menu in ConquerorX by
   hovering (tooltips) or right-clicking on each icon.
3. If a future session wants a proper icon glossary, run OCR /
   visual identification against the 13 image files and record the
   mapping in [`11-glossary.md`](11-glossary.md).
