32.3 Selecting Events for Printouts

On the right-hand side of the window, the tree structure represents the filtered events, with the games included in the event, and the players that participated in the games along with their scratch, handicap and total.

Select the sections to be printed from the tree-structure, then press Score or Standing , according to the report-style desired. Set the printout options in the window that opens.

Export

Select a play event, press Export , modify the file name if necessary and choose a folder to save the file in.

Game Eligibility

Through this button it is possible to change the Eligibility option previously in the Lane Options, between For the Center Average or not, or Official Games .

Select at least one event and press Eligibility to access the Eligibility options.
