15.2 Basic

Environment

BES Only

Click on the picture preview to choose the environment to be displayed on the lane monitors; in the window that opens, simply click on the environment picture to send it to the lane.

Select in the column on the right-hand of the window which YLYW Environments are available on-lane, for the Your Lane Your Way feature.

Click on Signature Grid to access the Signature Grid Setup, where it is possible to choose its style, colors and a mix of animation themes to be displayed, and to take a picture through the webcam to be use as grid background.

Practice

This option opens a window where it is possible to set the number of bowls or the minutes of practice allowed which can also be accessed through the Lane Control module.

In the Mode drop down menu, choose from the following:

  • Cycle where the pinsetter is to function normally
  • No Cycle if the pinsetter is not to perform cycles during practice bowling
  • Full Set if all pins are to be reset after each bowl.

Press Manual if the players wish to decide when to stop practicing by pressing the red button.

Press No Practice to deactivate the practice session.

Classic Game & Skill Games

This option allows the choice between three Classic Games (No Tap , Low Game , Odd/Even or 3-6-9 ) and setting the rules for them.

Special Games

Choose the Special Game sessions to be played by clicking here. A window appears where the desired session of one or more Special Games can be assigned to (or removed from) lanes.

By choosing to send a BES Birthday Party to the lanes, the Birthday Photo button appears in the bottom right hand corner: press it to access the Birthday Party photo settings.

YOUTOONS

This option allows you to take bowlers inside a game. As soon as they take their picture, the game begins. YouToons merges those images into the graphical animations, turning bowlers into hilarious characters on the screen. You can choose your favorite YouToons game from the drop down menu located at the top of the YouToons window. You can add, modify or delete any YouToons section using the three buttons at the top right of the window. Use the three buttons at the bottom of the window to take pictures that will be merged into the graphical animations.

Special Games for All

Check this option if Special Games are to be activated for all players. It is then possible to deactivate any players not wishing to participate, by deselecting the Special Games option in their Bowler Options.

Deselect this option to deactivate Special Games on the lanes, activating only customers willing to participate.

Redemption

Choose one of the previously set redemption configurations.

Set None to disable the redemption ticket dispenser.

Bumpers

Activates the bumpers for the lane. Choose between Down , Game Only and Practice + Game .

5 Frames Mode

It activates 5 frames game.

Current Frame Format

Keyboard

This option enables the use of the on-lane keyboard.

It activates the Qubica Key in Bowland Centers and the Modifications tab in BES Centers (which contains the functions available from the lanes).

This option is available if the Keyboards have been previously enabled in Lane Setup.

Environment from Console

BES Only

Enable this option to allow the bowlers to choose the animation set from their console.

Animation

BES Only

Displays animation for 9 score, Strike, Spare, etc. on the lane monitors.

Sound

BES Only

Activates the audio on lanes.

Speed

This setting displays the speed of each ball throw on the lane monitor.

Spare Finder

BES Only

After the first bowl, the Spare Finder displays the remaining pins and the bowl necessary to achieve a Spare.

Choose which Spare Finder to activate in the scroll down menu between:

  • a Static picture,
  • an animation,
  • a Tutor suggestion: in addition to a themed animation, an instruction is displayed, explaining how to throw the second bowl, e.g. "Hit pin 1 on the right side to send it to the 2 pin". This Spare Finder Tutor is also present in a Fast version.
  • Statistics can be displayed for each of the players, regarding the highest score, best score, the number of Strikes, Spares, Gutters, etc...

Swap Lanes

Select this option so that players bowling on lanes opened in pair mode exchange lanes after a set number of frames played (1,2,5 or never).

Swap Every Game

Activates lane exchange of those opened in pairs, at the end of each game.

Disable Ball Cycle

This option allows the ball cycle function to be disabled, useful in the case of candlepin bowling.

Language

Select the language to be utilized on the lane monitors.
