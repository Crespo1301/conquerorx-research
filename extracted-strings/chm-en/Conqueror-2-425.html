4.2 Call Center Settings

Unsent E-mail Folder

Choose the shared directory where unsent e-mails will be saved. When a new booking is created, the confirmation e-mail is sent to the customer's e-mail address or saved to this shared folder as an XML file for batch printing and sending by mail. The e-mail may be "unsent" because the customer's e-mail address is incorrect or the Call Center has a (temporary) problem sending out e-mails in which case the confirmation e-mail is automatically saved by Conqueror.

Report Folder

Choose the shared directory where the reservations reports will be saved in XML format, after having generated them in the Consolidated Reports module.

Confirmation E-mail Templates

It is possible to create various booking confirmation e-mail templates, that are associated to each Reservation Type and are then sent or mailed to customers after making a reservation. In order to create a Confirmation E-mail Template press the E-mail Template button and then New to create a new e-mail template.

Specify a name for the template, enter your customized header and footer and then press Preview to check it. After which you can Modify it if necessary and finally Save. When the various templates are ready, close the window and enter the Reservation Types menu - inside which it is possible to associate an e-mail template to each Reservation Type by selecting it from the E-mail Template drop-down menu.

E-mail Protocol Settings

Setup > Center Setup > Basic

Enter the E-mail Protocol Settings.

Number of Versions to Maintain

Setup > Center Setup > System

Call Center operators can connect to remote centers running different (the same or earlier) versions of Conqueror Pro provided that the Call Center terminal has the earlier QDesk folder saved in the same directory as the "active" QDesk folder for the currently-installed Conqueror version running at the Call Center.

The number of versions to maintain option specifies how many older QDesk folders to keep in order to maintain backward-compatibility with remote centers running older Conqueror versions.

The number of versions that can be kept must be between 2 and 10.
