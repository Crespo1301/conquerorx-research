4.1 Game Mode

Frame Payment

This payment mode considers frames as the unit of measurement, instead of games.

By selecting this option, the Games column in the Lane Control window is labeled Frames .

Pay 11th & 12th Frames

BES, Bowland and Bowland-X Only

When utilizing frame payment in Post-assigned mode, specify if the 11th and 12th frames are also to be included.

Price Evaluation Mode

If playing in Pre-assigned Mode , the price key valid at Opening Time may be considered, or that being utilized at Selling Time . For example, when selling more games (at 3 pm) to a lane that was opened an hour previously (at 2 pm), through this option either price can be utilized, i.e. that applicable at 2 pm (opening time) or at 3 pm (selling time).

The same applies when using Post-assigned Mode : the choice between Opening Time or Closing Time with the additional possibility to calculate the Proportional price of the game.

For lanes opened in game mode with the Proportional Starting Time option enabled, each game is paid for according to the price key valid in the moment the game starts.

Proportional prices are available only in BES, Bowland and Bowland-X Bowling Centers.
