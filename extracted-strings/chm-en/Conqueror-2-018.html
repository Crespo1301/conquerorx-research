4.3 Table

In the table (the lower part of the screen), messages are ordered chronologically according to important messages that have not been viewed, important messages that have been viewed, and all other messages.

  • If the message is checked, it has been dealt with,
  • if marked with an asterisk, the message is yet to be seen,
  • if the message is marked with an exclamation mark, it is of great importance.
