5.1 Creating Price Keys

In order to create a price key, select the Price Keys tab and then press New .

The following details must be inserted:

Name

The Name of the price key, i.e. a brief description of the item that the price key refers to.

Price

Here it is possible to enter a Price (which can also be a dynamic price).

Tax Group

Select the Tax Group to be applied to this price key.

Quantity

Insert the quantity of the product to be sold at a time, in the Unit of Measurement defined when creating the department.

Berg Code

This option is only available in the Food & Beverage departments.

Enter the price key code for Berg beverage dispenser.

In the case the same Berg dispenser is used in two (or more) different Conqueror Pro terminals (by connecting the Berg dispenser to a switch), it is necessary to:

  • duplicate the price keys that are used by more than one terminal
  • assign different codes to the duplicate price keys
  • specify, for each price key, which code is valid on which terminal

RecTrac Code

Enter the price key code for RecTrac.

WinTic Code

Enter the price key code for the export to WinTic.

External Key

If working with a third party program, set the relevant External Key .

Bar Code

Enter the Bar Code of the price key (in cases where the Center has the appropriate scanning device).

Gratuity

The gratuity is automatically calculated and added to the bill if it includes at least an Always Consider price key. The price keys considered in order to calculate the gratuity are all the price keys set as Always Consider and the price keys set as Optionally Consider .

The gratuity is not calculated in bills including only Optionally Consider price keys: it is necessary to have at least one Always Consider price key in the bill in order to have a gratuity automatically applied.

When a gratuity is applied, price keys set as Never Consider are not included.

Special Price

Check this option if the use of the price key has to be tracked (such as price keys priced "0.00", for free items).

The transactions containing Special Prices are listed and highlighted in the Shift reports.

Authorization Required

This function allows the manager to control the sale of particular items. To use this price key, the operator should have special permission (the privilege Sell Authorization Required Price Keys , in Setup > User Profile Setup).

A new Authorization Required (2) option with a specific User Privilege has been added, in order to manage dedicated price keys of different types (e.g. some discounted price keys can be reserved only by managers, while others can be used also by operators managing reservations).

Set the price keys to be dedicated to a particular profile as requiring the authorization 1 and/or 2 (Setup > Price Setup > Price Keys), and then assign the Sell Authorization Required (2) Price Keys user privilege to the User Profiles (Setup > User Profile Setup > Operate).

Package Only

Check this option if the price key can be used only to compose a package, and is not to be sold directly.

Members Only

This option is used for the sale of specific price keys (for instance lockers have this default option) to Frequent Bowlers Only .

Shoes

The Shoes option is available only when referring to the Shoes & Socks department. If various types of shoes have been set as Fast Sale Items, set this option to prevent the operator from renting (and therefore charging) more than one pair of shoes to the same player.

Sale Price

The Sale Price option allows the operator to change the price when selling an item (it is only possible to set it for price keys belonging to the Bar, Pro Shop, Income, Expenses and Deposits).

This is especially useful for the Deposits module, in order to insert the amount received as a deposit, which can vary according to the situation.

Point Collection

Enable this option if the present price key is valid for Point Collection and Player Club Cash according to the rules set for the whole department in the FBT > Point Collection.

Discountable

This option is enabled by default and can be disabled in order to prevent a price key from being discounted, thus excluding it from discounts applied to the entire bill (e.g. alcoholic drinks).

This option is also available for packages. In this case, the Discountable option of the single items making up the specific package will be ignored.

Note Required

Set a mandatory note to price keys and packages. If a note is not entered during the Sales phase, it will not be possible to proceed with payment.

Best Prices

Enable this option if the present price key has to be included in evaluation of Best Prices for the Extended Availability feature.

Kitchen Printable

Specify that the price key has to be printed in the kitchen orders.

Proportional

This option is activated only when referring to sub-departments whose unit of measurement is Time . It allows the division of the time to be paid into minutes.

Applicability Dates

Press Applicability to restrict the sale of a price key only in a specific date range; prices can be defined to be available starting from a specific date, until a specific date and between two dates (time limited promotions); moreover, it is possible to define specific calendar days in which the price key cannot be sold.

Therefore specify the range of dates in which the price key can be sold, by choosing from a specified Range of Dates , From a Date or Until a Date .

Press + to specify a calendar day in which the price key is not available for sale (e.g. it is possible to define special prices that apply during the Winter Holidays, from 15th December to 10th January, but not on 24th, 25th and 31st December).

In the Sales window price keys that are not currently saleable will not be displayed.
