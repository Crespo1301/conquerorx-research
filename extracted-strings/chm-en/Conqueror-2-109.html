15.5 Modifications

BES Only
This tab is enabled if the Keyboard option is checked in the Basic tab.

It permits the players to activate the following functions directly from the keyboard.

Correct Bowler

This activates the Correct Bowler function on the lane keyboard, enabling the modification of player information.

Modify Bowler Name

Allows the modification of the name of the current player.

Modify Bowler Handicap

Allows the player to correct their handicap.

Change Line up

Allows the players to change the line-up of the current game.

Edit Blind Score

Allows players to edit a Blind player's score if corrections are necessary.

Skip/Unskip a Bowler

Allows the players to pause for a player that has to skip frames (if they are absent for a few minutes).

This pause cannot continue past the current game; therefore this option must be removed in order to finish the game.

Modify Bumper Status

Allows the deactivation of the bumpers.

Modify Bowler Gender

Allows to correct the gender of the player on lanes.

Modify Bowler Hand

Allows the player to correct their hand, between right-handed and left-hander.

Edit Prebowled Scores

Here the players can insert, modify or cancel the total scores of pre-bowled games.

Select Special Game Bowler

Permits the players to choose whether they wish to participate in the Special Games.

Substitute League Bowler

Allows the players to replace a league player with a substitute recognized by the system through their ID.

Edit No Tap Values

Allows the players to modify the values for the No Tap Classic Game.

Add/Remove Bowler

Enable various bowler modifications:

  • Add Regular : a new team member can be added here.
  • Remove Bowler : a league or team member can be removed here.
  • Add Pacer : allows a Pacer to be set or another player to be indicated as a Pacer.
  • Add Best Ball Bowler : allows the setting of a virtual Best Ball Bowler. The Best Ball Bowler's game is constructed by the system selecting the actual players' best bowls.
  • Add Best Frame Bowler : allows the setting of a virtual Best Frame Bowler. The Best Frame Bowler's game is constructed by the system selecting the actual players' best frames.

FB Sign in

Enable to allow the members to sign-in from the lane console by entering their FB ID. Members who sign in by themselves from the lanes will be highlighted in the Lane Status so the operator can easily identify them.

Correct Team

This activates the Correct Team function on the lane keyboard, enabling the modification of team and player information: Correct Team Name and Correct Team Handicap , allowing players to modify their team name and handicap.

Display Card Hands

Enables the Poker Hand option on the keyboard, that allows the display of the cards received up to that moment.

Give/Remove a Card

This option enables the Deal Card and Remove Card options on the keyboard, allowing the request or removal of a card.

For example, an extra card could be requested when a pin that guaranteed a Strike, fell late and an undeserved card could be removed when a pin falls provoking an accidental Strike.
