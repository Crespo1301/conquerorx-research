10.1 Batch Summary

The amounts shown in the Batch Summary include Credit Cards and Debit Cards transactions.

Pressing Close Batch button starts the completion procedure of financial transactions, i.e. it authorizes the debiting of the amount due. When it has been pressed, it is impossible to void transactions, which pass from the Executed status to the Closed status.

It is advisable to perform this task daily.

Web Transactions are not displayed together with the Local Transactions, but separately.

To switch from Local to Web or to Web to Local, use the new button Web/Local in the control panel.

The control panel, the Close Batch feature and the Summary regard the table currently selected.
