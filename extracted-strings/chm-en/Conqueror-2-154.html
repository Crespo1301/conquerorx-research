1.2 Experience Setup

First, you need to add an Experience to start using this new functionality. Select Experience Setup module to create, modify or delete an Experience. There are six buttons located at the bottom of the Experience Setup module. Click New to add a new experience, Select an experience and click Delete to delete it

Select an experience and click Modify to modify it. Use the Up and Down arrows keys to move an experience up or down. The Enable Experience selection mode option allows you to enable\disable all the components of the feature. You could use this option to setup the Experiences in advance and enable them at a later stage. For each Experience, you can define: a name, a lane set in which the Experience can be used, colors to facilitate the selection of the Experience, an exhaustive description of what the Experience includes to help the operator.

Setting up Game/Time/Unlimited Price Keys

Use Game/Time/Unlimited Price keys tabs to select the price keys you want to add to the Description list, which includes all the price keys that belong to the Experience you are just about to create. Flag the price keys and use the small arrows to add/remove them from the Description list. Set a default price key for each opening mode prior to using an Experience. Please note: FB price key cannot be set as default. You must set a proportional price key when it comes to Time Price keys. Select Save to confirm your changes or Cancel to return to the Experience Setup module. Once the experiences have been setup, they are ready to be used.

Setting up Environments

Use the Environments tab to add an environment to the experience. Use the Game duration options if you want to filter the environments by number of frames (10 or 5). To save the options, you must first set a Default Lane Option and a Default Environment using the dropdown menu. The players have the chance to change environment from YLYW, choosing from the ones you have previously included in the Experience. Select Save to confirm your changes or Cancel to return to Experience Setup module.

Selecting an Experience

When opening a lane, a window prompts the operator to select an Experience. The available experiences depend on the opening mode and the lane set. The Experience list dialog window pops up so that the operator can choose the Experience compatible with the opening mode and the lane set. If the default price key is not available at that time, the Experience will be greyed out and it will not be possible to select it. Click Skip to open a lane without Experience or Cancel. The system works as usual if no Experience is available. Please note: only privileged users can open a lane without selecting an Experience.

Lane Control - Set Price

Open Lane Control, click Select Price to visualize all the price keys compatible with the selected experience. The operator cannot: use price keys not compatible with the selected experience and change the list of available environments in YLYW. Click Experience to select a different Experience. You cannot change experience if the lane is open.

Lane Control - Lane Options

The operator can select a different environment from Lane Options. Only environments compatible with the selected experiences are available in Lane Options.

Merge/Transfer/Split

Merge: only available if both lanes are compatible with the selected experience.

Transfer (Lane/Bowler): only available if the destination lane is compatible with the selected experience.

Split: it is always available.

However, in case of emergency it is possible to transfer an open lane to one not compatible with the Experience lane set. The available environments\games remain those set up in the Experience (and compatible with the lane features). In this situation, the operator is notified and if he confirms, the operation will be logged as suspicious action.
