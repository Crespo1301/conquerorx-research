5. Safe Mode

Safe Mode is Conqueror's terminal safety feature that prevents unauthorized persons from using a temporarily unattended terminal: in Safe Mode a screen saver is displayed, preventing Conqueror access until a registered operator identifies themself. This is done either through fingerprint recognition, swiping the membership card or inserting the User Name and Password in the Log on panel (the default which is displayed is the previous user).

The Safe Mode panel displays the user name of the previous operator, which can be changed by pressing Change whereby another user can access the terminal through the Log On panel.

To immediately activate Safe Mode manually, press on the Safe Mode Quick Button in the main menu external frame.

It is also possible to set the terminals using Conqueror to enter Safe Mode automatically after X seconds. In this case, the number of seconds is entered in Center Setup.

SECURITY > Safe Mode
