2.8 Sticky Notes

Sticky notes gadget is a notes application included in Conqueror. It is displayed only when the operator is on Home > Quick Access menu. Sticky Notes can be removed but cannot be moved and pinned anywhere else on the screen; therefore, they will always be on the right-side of the main screen. The notes stretch with the text, once the sticky note reaches the bottom of the screen, it will no longer be possible to add text. Even if the operator disables this function, the number of items on the main menu will not be affected by it and continue to be nine.
