24.3 Bowling Mode Setup

Setup > Bowling Setup > Bowling Modes

Here it is possible to create new Bowling Modes and modify existing ones.

Select a Bowling Mode from the scroll menu to view its settings (Description , Set of Lane Options , Message , price keys, etc.), to Delete it or to modify it.

Creating a Bowling Mode

Press New to create a new Bowling Mode, then insert a name and Description .

Set of Lane Options

Select from the scroll menus which Set of Lane Options for single/pair of lanes.

Message

Choose the Message to send to the lane for this Bowling Mode.

Default Price Keys

Choose the default price key for game/time/unlimited opening, for the extra frames and for Time Games .

Opening Mode

Define the lane Opening Mode for this Bowling Mode (the Opening Modes set in Center Setup are proposed by default). For example, a Bowling Center may wish to set Saturdays as not having Unlimited play, therefore setting Game and Time as the primary and secondary modes and None as the third mode.

Unlimited Default Mode

QAMF Scoring Systems Only

Specify a limited duration or a closure time for Unlimited Mode.

Lane lighting

Click on Lane Effect and Global Mood to open a dropdown list. Choose a new Lane Effect or/and Global Mood from the list.

External Devices

Then choose whether the External Devices set for the Centre (such as glow lights, foul units, etc.), should be turned on or off for that Bowling Mode.

Console Lights

Decide the light color for when the lane is open and another one to use when lane is close.

By clicking on the Open Lane and Closed Lane fields, the color selection window will be open.

After the choices have been made, the colors selected appear in both fields.

This will be the default value, in the case the Lane Option is not modified at lane opening.

Extend Bowling Session

Lane Lighting

Click on Lane Effects or Global Mood to select a new combination of Lane Effects from the drop-down list, this helps you define Lane Effects and Global Moods separately. Lane Effects and Global Moods can also be defined for different lane sets.

Time Zones

Define the Time Zones for which the Bowling Mode is to be activated.

If the same Bowling Mode is to be applied to the whole table, select it in the scroll down menu and press Apply or Enter on the keyboard.

In order to assign the Bowling Mode to a specific time zone, the whole table must be deselected by clicking on All . Then, select the area of the table (day of the week or specific time by clicking at the beginning of a row or at the top of a column) to which the Bowling Mode has to be to applied and press Apply . If the Bowling Mode is not to be sold in a particular time zone, select it and press Deactivate and the area concerned is cleared.

To select an interval of time, press the Shift key on the keyboard and click on the first and the last cells of the desired area. If single cells of the table are to be selected, press the Ctrl key on the keyboard and click on the cells to be selected.

To scroll through the timetable displaying the three different time zones of the bowling day (divided in 30 minute cells) use the two arrows on the right. Here the earliest time displayed is the one set as Day Changing Time.

The last three columns of the table, called EX1, EX2, EX3, represent three extra holidays that each Center can define for its particular needs, by going to Setup > Calendar Setup.

MMS Service Set

An MMS Set is a predefined set of MMS services, which defines what goes on every monitor when a given bowling mode is running. By default, all bowling modes share the same Service set, i.e. the only MMS configuration that the center has been using until the upgrade. From the MMS Setup, centers can override "on the fly" what goes on a given monitor (e.g. the scoring of a tournament's final), without altering the default configuration. The default service will come back on when the bowling mode changes again.

To add an MMS Service, use the New button and choose an MMS Service for each monitor. Once the changes have been saved, select it from the MMS Service Set drop-down.

The ability to schedule MMS by bowling mode does not require any license.
