10. Exporting and Importing FB Data

Exporting Member Data

Back Office > FBT > Export FB Data

The frequent bowler archives for individual members (not for groups) can be exported through this module.

Press the Export FB Data section in the main menu to access the Export Member Data panel. Here the file path can be found by clicking in the File to be Exported bar (by default the last path entered is proposed).

Choose between Exporting All Members or Exporting New or Modified Members Only .

If Export is pressed but the file selected for exportation already exists, the system requests permission to overwrite it.

Importing Member Data

Back Office > FBT > Import FB Data

Press the Import FB Data in the main menu to access the Import Member Data panel. Here the file path can be found by clicking in the File to be Imported bar (by default the last path entered is proposed).

In case of a large number of members to be imported, it is recommended to select the Quick Import option and to choose the relevant behavior the system has to follow in case of similar members, from:

  • adding new members (in this case the operator must check if doubles have been created, using the Duplicated Members module),
  • overwriting existing members,
  • skipping importing similar members.
