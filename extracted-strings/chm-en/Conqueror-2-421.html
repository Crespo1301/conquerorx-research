2.1 Creating a Reservation in a Chain Center

When the Call Center operator is connected to the remote center, a welcome window opens where they can define all the basic reservation details in order to speed up the reservation process. Select the booking date and time, enter the number of players and press New . The Booking System opens and the New Reservation dialog is prompted, with the basic data previously defined, automatically set.

Note that the default Number of Players is the value set in Setup > Center Setup > Reservations. Alternatively the operator can press the Reservations button to access the remote center's booking system and create bookings from there as normal. When an operator with the user privilege to view the Conqueror User Messages connects to a remote center, the User Messages window is skipped during login in order to speed up the booking procedure.

When a Call Center operator is connected to a remote center, the center name is displayed in the external frame title instead of the operator name. By clicking on this center name, the operator disconnects from the remote center and returns to the Call Center window which allows them to change quickly between different remote centers. Note that in every window involved in the booking process (e.g. customer search, reservation search, new reservation, etc.), the window caption now also displays the name of the remote bowling center. The settings configured in Setup > Terminal Setup on the local Call Center terminal (e.g. terminal language, font type, printers, etc.) are maintained when the Call Center operator connects to the remote bowling centers.
