10.1 Tests and Direct Commands

You can run three tests: Test sensors, Test LEDs, Test bumpers and two direct commands: Bumpers Up and Bumpers Down. You cannot open a lane from another terminal while the test is running. To open a lane, you must stop the test first. To do so, click Stop test at the bottom of the window.

Test Sensors

This is the only test that provides automatic feedbacks; you do not have to check how the LEDs are performing manually as Conqueror displays the results instantly.

Overview tab: once you start test, the corresponding lane box turns red, yellow or green depending on the result. Red and yellow indicate the sensors are performing below a given standard.

Details tab provides more details about the status of the sensors. Each sensor has a bar indicating how its performance parameters. Two triangles, located at the top of each bar, displays the minimum and maximum tracked.

Test LEDs

You can easily verify the correct functioning of LEDs and identify possible issues. When the test is in progress, all the LEDs turn white at the same time, the corresponding lane box turns yellow and the label "testing" appears on it. The label disappears as soon as the test is completed. To stop the test press Stop test .

Test Bumpers

You can keep the bumpers up and down repeatedly (cycle). The number of cycles can be manually set. You can run the test on either single or multiple lanes. While the test is running, the corresponding lane box turns yellow and the label "testing" appears on it. The label disappears as soon as the test is completed. To stop the test press Stop test .

Bumpers Up/Down

You can select Bumpers Up or Bumpers Down to keep the bumpers up or down.
