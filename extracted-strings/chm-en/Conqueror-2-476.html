4. Com Test

Setup > Technical Setup > Com Test
RDB and VDB Only

The Com Test allows the operator to perform a communication test with the lanes.

Select lanes through Lanes to Test and press Start to begin the communication test.

When communication is functioning normally, the selected lanes are shaded green, and the 4 error types in each box are at zero.

If the system finds an error, the lane changes from green to red and the error type number increases by 1 each time.

At the base of each box there is a counter which displays the number of communication cycles already performed.

Press Stop to stop the Com Test.
