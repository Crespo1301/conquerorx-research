2. Basic

Security

Conqueror Security is enabled by default; each operator has to be equipped with a password and a profile in order to define which operations they can perform.

In centers using credit cards, it is not possible to disable it.

Password Expiration

This option allows managing the password expiration. By default it is enabled and set on Administrative Users Only . If choosing All User , the password rules will be applied to all the Conqueror operators.

Which are the Password Rules?

· Expiration every 90 days.

· Minimum length of 7 alphanumeric characters.

· The new password must be different from the last 4 already used.

Who are the Administrative Users?

An Administrative User is an operator with at least 1 (one) Management privilege marked with an asterisk.

Login Attempts before Disabling

Enter the number of times that an operator can make a mistake while inserting their password before being disabled for half an hour, after which they can try again to login.

Time Tracking at Log on/Log off

Check to link the Time Tracking system to Conqueror user log on/off, whereby Conqueror proposes the Time Tracking window immediately after that of log on/off.

Automatic Safe Mode After

Set the number of seconds after which the terminals will automatically enter Safe Mode, at center level. Then, it is possible to customize it at terminal level.

To do this, click on Terminals in the lower part of the window and choose, for every terminal, if the Automatic Safe Mode has to be at center level, disabled or custom. By choosing Custom , the number of seconds can be entered in the dedicated column.

Both under Center Setup and Terminal Setup it is not possible anymore to enter a Safe Mode value higher than 900 seconds (15 minutes).

To deactivate the automatic Safe Mode , set it to zero.

Database Language

Here the language utilized for the center database can be viewed.

By clicking on this area the database language can be changed: choose the desired language from the scroll down menu and press Translate .

Display Translator Codes

Select this option to display an identification number next to each phrase in Conqueror that corresponds to a code in the Translator software, so that translators can easily trace phrases when necessary.

Unicode Font for Strike Challenge

Enables the support of Unicode international characters.

Mask Language

Bowland and Bowland-X Only

Choose the language from the drop down menu, to be applied to the score grids.

Speed Unit

Here choose the unit of measurement (between km/h and m.p.h. ) to use for displaying the speed of throws.

Paper Size

Choose between the A4 and Letter paper formats, for the system printers.

Normal/Compact Report Font

Here the two fonts utilized for the reports can be chosen.

The first font is utilized for the titles, in the footers of reports, etc. while the second is utilized for the column content where the font is more compact as the space is reduced.

Current Bowling Day

The Current Bowling Day default is set as the System Day of Week . When using the default setting, the price keys utilized are those set for that day of the week.

When a public/bank holiday falls during the week, for example on a Tuesday, the holiday price keys should be applied (e.g. EXTRA1) instead of those used on normal Tuesdays. If this holiday has not been programmed in the Calendar as EXTRA1, the system can be programmed to function as it would through EXTRA1.

This manual setting is valid for one bowling day and therefore when the date changing moment comes, the setting returns to the System Day of Week .

The Current Bowling Day is displayed in the external frame of the Main Menu.

Modifications of this setting are registered in the System Log.

First Day of the Week

Select which day is to be considered the first day of the bowling week in the Calendar, for the price key/bowling mode table, in the reports, etc.

Day Changing Time

Set the time at which the system changes from one day to the next.

For Bowling Centers that close after midnight, here the time that the Center finishes trading for the day can be set so that sales made after midnight are still considered part of the previous day's takings.

For example if the Center closes at 2 am and re-opens at 6 am, it is advisable to set the day changing time to 4 am, so as not to risk performing operations on the wrong day.

System Date/Time

These two fields contain the system date and time settings, controlled by the Conqueror Server, with which all Conqueror terminals in the Center are aligned.

Manual modification of these parameters is viewed as a suspect operation and is therefore registered in the System Log.

External Time Server/Et-Host Time

Choose whether or not the Conqueror Server is to be aligned with the time and date of an External Time Server (for example that of the local network) or the ET-Host.

By selecting the External Time Server, the previous System Date & Time fields are deactivated and therefore cannot be modified manually as they are aligned automatically with the External Time Server.

By selecting the ET-Host option, the Conqueror Server aligns itself with the ET-Host data, which can be modified manually in the system time and date fields.

Default Report Export Format

Here the default format for report exportation is set by selecting the following formats in the scroll down menu: doc, pdf, xls, xml.

Desktop Message

Enter here a message which will be displayed on all terminal desktops, under the Main Menu upper bar.

Specify its font size and press OK .

E-mail Setup

Click here to enter the settings related to the outgoing e-mails.

Click on the E-mail Setup button to access the E-mail Protocol Setup window and configure the SMTP settings related to the outgoing e-mails from Mail Merge, Web Reservations, Call Center, in order to send e-mails directly from Conqueror without needing to open the mailing software. By default, qubicaamf.com SMTP is used (and the sender is qubicaamf.com), but it is possible to send these e-mails from the SMTP center server address.

The number of seconds to be entered as Delay between 2 e-mails sent has to be set accordingly with the values suggested by one's Internet service provider.

Configure a Time-out delay for the SMTP e-mail settings: when the number of seconds set here as timeout has elapsed, the e-mail sending fails (for example in the case of e-mails with big attachments). This is set to 100 seconds by default, but it can be modified.

Boss Password

Press to access the window where the Boss password can be modified.

Boss is the virtual administrator Conqueror user that has all privileges and can perform important and risky operations. In general the system administrator has this password, that is, the manager or a user with the authority and competence to manage the more sensitive areas of the system.

An option allows disabling the BOSS user. Procedure:

· Check that one User Profile at least has all the privileges, including the Change Administrative Password privilege.

· Enter Conqueror Pro with this User Profile, and go to Setup > Center Setup.

· Press on BOSS PWD and click on the Disable BOSS User option to disable it.

· Save.

Print License

Allows the printing of the Conqueror Software License Agreement complete with a table containing the Purchased Modules .

Terminals

Only the BOSS User can access the Terminal License Setup , utilized by the installation team to activate the acquired modules on the various terminals. Note that this function is accessible only if there are not any other Conqueror Pro terminal currently running.

Click on the license to be moved and use the arrows (up and down) to choose the destination terminal.

If the automatic Safe Mode is enabled at center level, it is possible to customize it at terminal level through this window. Choose, for every terminal, if the Automatic Safe Mode has to be at center level, disabled or custom. By choosing Custom , the number of seconds can be entered in the dedicated column.

Activation

Allows the insertion of the activation key.

The activation key is text in code that, when inserted into Conqueror, activates the modules that require licenses, such as the Booking System, Advertising, etc.

When new modules are purchased and when a new version is installed, the activation key is modified and will have to be re-inserted using this option in order to substitute the previous one.

The Search button allows the acquisition of the activation key from the directory in the computer upon which it was saved.
