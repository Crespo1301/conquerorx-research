3. Reporting

Back Office > Reporting > Consolidated Reports

A new module allows operators with the Access Consolidated Reports Module user privilege to export the data contained within the Outstanding bookings, Deposit due, Revenues and Canceled bookings reservation reports for a specific date range from any or all of the remote centers defined in the Call center setup module into xml format files, where each report is labeled with the center name and report type (e.g. PlanetBowling_RevenuesReport.xml).

The remote Centers are listed in a table and selected by default. It is possible to unselect some centers if necessary, then set a Date Range (between which the reservations were inserted) and select one or more of the reservation Reports from the four available. Note that the date filter criteria applies to the following dates for each report type:

  • the Outstanding Bookings report uses the Full Payment Due Date,
  • the Deposit Due report uses the Deposit Due Date,
  • the Revenues report uses the Insertion Date,
  • the Cancelled Bookings report uses the Cancellation Date.

During the process, the download status is displayed in the table and it is possible to interrupt the download at any time by pressing Cancel . The download status can be:

  • Downloading - download is in progress,
  • Completed - download procedure has been completed successfully (and the downloaded reports are available),
  • Cancelled - the Cancel button was pressed and the download procedure has been interrupted,
  • Connection Error - the connection timeout was reached or the remote center was not reachable,
  • Saving Error - the specified Report Folder is incorrectly configured.
