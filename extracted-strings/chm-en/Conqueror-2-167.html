4.2 Conqueror Pro Settings

Configuring the Personal Cash Drawer Management

Setup > Center Setup > Shifts

Enable the Personal Cash Drawer option in order to work with this new drawer management: the system checks if there are Shifts opened (not already printed), and then restarts.

When restarted with the Personal Cash Drawer management active, the Sectors & Cash Drawers tab is hidden and it is replaced by the new Cash Drawers tab.

Setting Personal Cash Drawers Values

Setup > Center Setup > Cash Drawers

In the Cash Drawers tab, a Personal Cash Drawer called with the name of the cashier is automatically created, with a default Bank.

Click on Modify to change the cash drawer name and the bank amount.

The Under/over Limit can be managed if the Stricter Under/over Management option has been enabled in the Shifts tab.

Please note that when a new staff member is added in the system, a new Personal Cash Drawer is automatically created with their name.

Connecting Hardware Cash Drawer to the Terminal

After having set the Personal Cash Drawer management in the Center Setup, it is necessary to configure the hardware cash drawers.

On each terminal it is possible to set 2 cash drawers under Setup > Terminal Setup > Devices.

Configuring the Printer Profiles

If the Printer Profile for All Counters was enabled in the previous management, it remains enabled and the Printer Profile is active for all cash drawers.

If different profiles were associated to the cash drawers (Printer Profile for All Counters option deselected), it is necessary to associate a Printer Profile to the new cash drawers (1 for each operator), otherwise the order will not be printed in the kitchen.

Assigning User Privileges to Cashiers

  • Visualize all current shifts of the bowling center

Only cashiers with this privilege can view shifts pertaining to other operators.

  • Manage cash drawer sessions and shifts opened by others

Only cashiers with this privilege can view, park, close and print shifts pertaining to another operators.

  • Work on shifts through different terminals

This privilege allows operator with a hardware cash drawer to work on a shift from different terminals.
