6.2 Log off

Once inside the system a new user can log-on, replacing the existing user by pressing Log off in the Main Menu, whereby the Log on panel appears for the next user to log onto the system.

Conqueror remains open with the Log on window open in the foreground, ready for the next user.

Logging off is also accessed from the Quick Button in the external frame, hereby closing all modules used by this user.

All open transactions, such as outstanding payments, sales, deposits or the like, must be dealt with before the operator is permitted to log off.
