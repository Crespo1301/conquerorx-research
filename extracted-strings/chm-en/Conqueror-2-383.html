8. Booking System Settings

Setup > Center Setup > Reservations

Here the Booking System can be molded to cater perfectly for each Bowling Center.

Grid Time Unit

The unit of measurement in the Reservation Sheet is based on the minutes entered here (preferably 10 or 15 minutes), which is also the minimum amount of time that can be booked. The unit of time set here is visible on the Reservation Sheet as vertical broken lines.

Lane Status Advice Time

The number of minutes inserted here indicates how far in advance the reservation relative to a specific lane is displayed in the Lane Status window with the Reserved label and the starting time.

Start Auto-allocation from Lane...

Select the lane from which the system starts to propose the first lane compatible with the reservation being created. Here it is advisable to select one of the least used lanes to ensure equal 'wear and tear'. For example in a Bowling Center with 24 lanes where the first 12 are used more than the next, setting the 13th lane here, proposes suitable lanes from that lane onwards so that the other 12 lanes are used more than the first 12. This setting works best in allowing balanced lane usage when changed at regular intervals.

To evaluate the 'wear and tear' of the lanes with more precision, see Lane Usage Reports.

Arrival Time in Advance

Specify how much time in advance the player must arrive in order to allow adequate preparation time before the game. At the set Arrival Time, if the booking has not been set as Arrived, the reservation will automatically be labeled Late.

This setting can then be modified in the Reservation Details window.

Suggested Maximum of Players per Lane

This option limits the number of players per lane, in order to maintain a steady pace when playing and must be less than or equal to the maximum set in Center Setup. When this limit of players is exceeded, another lane is automatically assigned. For example if the Bowling Center chooses to set a maximum number of 10 players and 8 players as a Suggested Maximum here, when creating a booking and setting 9 players, the system proposes that the booking be set on two lanes instead of one. This is only a suggestion, whereas if the number of players is over 10, the reservation will occupy an extra lane.

Resource Type

Select the Bowling Center's resource (bowling session or Time Game) from the scroll menu and set the default Number of Players , the default Number of Games or the default Time in Minutes ; this option is given in the New Reservation window.

Meals

Here it is possible to set the capacity of the restaurant, that is, the number of people that can be served meals in the restaurant/snack bar during a certain time span. In the space next to Kitchen Shift Length , indicate the length of time in minutes into which each Shift is divided. In the space next to Maximum Number of People per Shift , indicate the maximum number of people that can be served in the restaurant during each kitchen Shift.

Opening Hours

Define the time frame within which it is possible to allocate a reservation within the Reservation Sheet, a time frame that can be visualized outlined in red on the Reservation Sheet. Set Always Open if it is possible to play/reserve games without interruption for 24 hours. The setting From... To... excludes the time that the Bowling Center is closed.

Reservation Types

In this window it is possible to create new types of reservations and modify or remove ones that already existing.

To create a new Reservation Type press Add and give it a name, e.g. National League.

Enable the Type by Default option if the current reservation type is the one to be set by default when creating a new reservation. To change the default reservation type, enable another reservation type: the one set previously will be automatically disabled.

If desired, assign a Bowling Mode and then choose the details to be displayed in the Reservation Details window from: Lanes , Meals , Payments , History , Staff Requirements , Time Games (a tab for each Time Game is displayed).

Select the Confirmation E-mail Template to be associated to the Reservation Type . The e-mail templates available in the scroll down menu are those previously set in Center Setup > Reservations > Template Setup.

If working with a third party program, set the relevant External Key .

In the lower section of the window, colors can be set for the types of reservations making them easily distinguishable: select the Reservation Type in the table, choose the colors by clicking on the Background , Text and Border box and choose if the reservation rectangle has to blink. If these changes are satisfactory, they can be set as default for that Reservation Type by pressing on the little save button. If the new settings are not to be set press the little reload button, which recalls the previous default colors.

Service Reservations relative to the management of the Bowling Center are used to block lanes to allow time for scheduled maintenance and the like (or to keep lanes free for walk-in trade). These are not real reservations and do not follow the logic of a normal reservation, therefore when setting a Service Reservation , the other options remain disabled.

To delete a type of reservation, select it in the table and press Remove .

Reservation Status

Here it is possible to set a color for each reservation status: select the status, set the colors and close.

Press the Color Table button in the Reservation Sheet to see the legend of values set.

Group Types

Here it is possible to define and modify the type of organization of a particular group e.g. Schools, Scouts, etc. This information will be available in the FBT module, when a group is created.

Professions and Workplaces

Allows the operator to define and modify the job description of a group.

This information will be available in the FBT module, when a group is created.

Discover Sources

The Discover Sources (that is how/where the customer first learned of the Bowling Center, like radio, TV advertising, newspaper etc.) can be defined or modified. The information can be used for marketing purposes.

This information will be available in the FBT module, when member/group is created.

History Log Types

Here one can create informative messages that can then be chosen and inserted into the Customer History and the Reservation History by clicking on the Log button in the Reservation Details window.

Subtract Time from Late Bookings

Tick this option if the operator is to be given the choice to reduce the length of timed bowling sessions when the customer is late, incurring full payment of the reservation regardless of reduced playing time (in such cases a window appears whereby the amount of time to be subtracted from the booking can be entered). If this option is not selected, the original booking time remains valid, delaying all subsequent bookings.

Incoming Reservation Delay (Minutes)

Insert here how many minutes in advance the incoming reservations have to be displayed in the Tab module.

Promotion Setup

Web Promotions require a specific Conqueror Pro license

Marketing campaigns can be managed to promote phone and/or web bookings based on discounts or special prices: by specifying the relevant code at booking time, customers can access the special conditions related to that specific promotion.

In the New Reservation window, a dedicated field called Promotional Code allows operators to insert the promotional code; if the Promotional Code does not satisfy the related constraints (validity dates, minimum amount required, sales channel), the operator is warned. Checks on the promotion validity are done also when changing the reservation start time.

In this window the center can define marketing campaigns. Customers can receive promotional advantages if they specify a Promotional Code at booking time and if they respect the Validity Dates and Sales Channel (web, call center and/or local).

The promotion can be based on:

  • Discounts : in this case, select one of the discounts previously set in Price Setup and the Minimum Reservation Amount Required to take advantage of the promotional discount.
  • Dedicated price keys : in this case it is possible to choose special price keys that will be available only for customers who have specified the related Code . Click on the yellow field to open the whole price key structure and choose all the price keys to associate to the promotion. Click on a department to display its price keys, then select the price keys and press the assign arrow. Similarly, in order to remove a previously chosen price key, select it and press the remove arrow (it is possible to use the multiple selection of price keys by pressing the Ctrl key on the keyboard).

Tracking Only campaigns can be set for statistical purposes.

E-mail Template

Call Center Only

When the new booking is created, the confirmation e-mail is sent to the customer e-mail address or saved to a shared folder for batch printing and sending.

To create a Confirmation E-mail Template press New , specify a name for the template, enter customized header and footer and press Preview to check it. Modify it if necessary and Save .

When the various templates are ready, close the window, enter the Reservation Types window and associate a template to each Reservation Type by choosing it in the E-mail Template scroll down menu.

Fee Setup

Fees applied to reservations can be:

  • a Fixed Amount : in this case, the amount entered here will be charged to each web reservation.
  • a Percentage : in this case, the fee will vary with the reservation total. Enter here the percentage to charge.
  • a Fixed Amount per Game : in this case, the amount entered here will be charged for each game included in the reservation
  • a Fixed Amount per Player : in this case, the amount entered here will be multiplied by the number of bowlers included in the reservation

For the last 3 options it is possible to set the minimum fee that has to be charged and the maximum fee that can be applied. E.g. Enter 1 as the minimum fee in order to charge $1 even if the fee calculated is lower than $1. Enter $10 as the maximum fee in order to charge $10 even if the fee calculated is higher than $10.

These settings only affect local reservations. In order to manage fees for web reservations, similar settings have to be specified in Web Setup.

To void or remove the predefined booking fee the relevant privilege is required.

Provisional Auto Delete Setup

This panel contains settings that determine the automatic elimination of Provisional reservations made by Individual Customers , Groups or Anonymous customers.

For each type of customer the operator can set when the Provisional reservation will be automatically deleted if the customer has failed to confirm their reservation.

Late Arrival Management

Specify here how Late Reservations are to be managed. Choose from:

  • Automatic No Show After ... Minutes
  • Automatic No Show at the End of the Day
  • Manual No Show : Manually setting No Show allows more flexibility. For example, when the Reservation Sheet is not full, the reservation can be moved if the customer is late.
  • Automatic Movement into the Overbooking Area : late reservations are automatically moved to the overbooking area after the number of minutes specified here has passed. This allows centers to free up the lanes for new bookings, to recover late bookings when the customer shows up and to arrange the customer on the next available lanes.

Reservation Confirmation

If this option is selected, a summary of reservation details which can be printed, e-mailed or made into a report appears as soon as a reservation has been saved. This is especially useful as written confirmation for customer or Center, of a reservation.

Display Original Reservation

Tick this option to visualize the original reservation (in bar form) underneath the actual reservation duration on the Reservation Sheet. This can be useful in cases where the reservation has been moved or delayed. Deselect if only actual reservations are to be visualized, i.e. for Centers visualizing many lanes full of bookings at once, the bar can take up valuable space.

Confirmed Reservations by Default

If a Bowling Center chooses not to work with Provisional reservations this item must be selected, if however the Center works with Provisional reservations, they remain Provisional until a deposit is obtained or the reservation is confirmed manually in the Reservation Details window.

Anonymous Reservations by Default

Select this option if reservations are to be set as anonymous by default, skipping the Member Search window when creating a reservation. Useful for Centers that don't always work with Frequent Bowlers, preferring to attach only a name, instead of a customer, to a booking.

Pay after Customer Arrival

This option can be selected if the Bowling Center wishes to refuse pre-payment, thus dealing only with deposits until the customer arrives and pays in full.

Use Quick Booking Window

Option for Bowling Centers using fast booking: when creating the reservation a simple window appears instead of the standard one. Only two fields have to be filled in: Customer and Notes .

If desired, by pressing the More button, the standard window will open and more details can be defined.

Show Lane and Player Details in Receipts

Enable this option to print the reservation lane and player details on the receipts. The player details printed are the name, the handicap, the gender, the player attribute, etc.

Dynamic Prices for Local Booking System

This option enables the Dynamic Prices also for the local Booking System reservations and not only to the booking website.

Close Reserved Lanes Still to be Paid

Enable this option to automatically close lanes related to reservations, even if they are not paid in full.

Deposit Default Value (%)

Set a default percentage to calculate the deposit the customer has to pay in order to confirm their reservation.

To allow reservations without any deposit, enter zero.

Days after Date of Insertion the Deposit Must be Paid

Enter how many days are available to the customer to pay their reservation deposit, starting from the insertion day.

Days before Date of Play the Balance Must be Paid

Enter the number of days before the date of play the reservation has to be paid in full.

Message of the Day

In this space the operator can write a message that will be visualized by all of the operators above the Control Panel of the Reservation Sheet. For example: "No league games are scheduled for today". This message remains the same until changed manually.

This can also be achieved by clicking directly on the Customer Space in the Reservation Sheet.

Extended Availability

Enables the search for the Best Prices within a time range through the New Reservation window.

The day has to be divided into four non-overlapping time zones. By default they are: Morning , Afternoon , Evening and Night .

Dynamic Pricing

Dynamic prices can be created for bookable bowling price keys: discounts can be applied automatically during non-peak hours, and higher prices during peak periods.

The dynamic price is automatically calculated and displayed accordingly with the setup; when the customer selects a price key that doesn't belong to any discount rule sets, the items are offered at the regular price (not discounted). Also, discounts and surcharges are automatically applied to bowling products only, so if a customer purchases a package including food and bowling, only the bowling part will be discounted/surcharged.

Sets of rules have to be created and then the price keys involved have to be associated to the sets of rules. Two sets cannot define rules for the same price key in the same period: the system automatically checks the correctness of the rules and warns the operator to avoid mistakes.

In order to create a new set of rules press Add , specify a Name and a Validity Date Range (the rule set is valid from ... to ...) and press OK . Now the different rules have to be created, and the price keys that have to follow the set of rules have to be specified.

Press on + to create a rule. Each rule that will manage the dynamic price is based on:

  • The day of the week: it is possible to create a rule to be applied on Saturday only, another rule to be applied from Monday to Friday, etc.
  • A time range: enter at what time the rule starts and ends (the rule is applied from ... to ...)
  • The number of days the customer books in advance: e.g. a rule can be applied only if the customer books a lane between 5 and 7 days in advance.
  • The occupancy calculation time range: it is a global setting for the Bowling Center; it is the amount of time to add to the starting time specified by the user, in order to define the period when calculating the Bowling Center occupancy. The minimum value is 30 minutes.
  • The Bowling Center occupancy: the price rule also considers how many lanes are booked for the reservation day and time, so a discount will be applied when the Center is empty and a surcharge can be applied if the Center is nearly full. The occupancy is considered as the percentage of lanes already booked within a calculation period. For example, to set a discount when 2-4 lanes are booked (in a center with a total of 10 lanes), enter 20 - 40 (%) in the Occupancy range.

Then enter the Price Variation as a percentage to be deducted or added to the normal price and save by pressing OK : the rule is now showed in the list, with the various parameters displayed in the different columns.

When making a reservation the operator can help the customer to choose the most convenient date & time by opening a screen displaying the Best Prices across 4 weeks. This screen is open by pressing Prices in the New Reservation window.
