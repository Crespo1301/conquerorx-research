12.1 How Does it Work with BES X?

Bowler Side

When tapping on the Food & Drink Orders menu item on the SuperTouch console, a window opens, and the bowler can browse and choose what to put in their order, displayed on the right-hand side.

To modify a price key quantity, the bowler selects the row in the order and adjusts it using the + and - buttons.

When pressing the Confirm button, a window appears prompting for a confirmation and allowing specifying the amount the customer will tender so that the operator can easily prepare the necessary change (if enabled).

Operator Side

When an order is sent from the bowler console, the new Urgent Tasks Quick Button blinks in order to warn the operator that an order is waiting for review.

Clicking on it, a window appears displaying all the pending lane orders; the operator clicks on the order they want to process and the POS module opens displaying the items of the lane tab and the items of the order. Here the operator checks the order, modifies it if necessary and confirms it, saving the tab and sending the order to the bar receipt printer and to the kitchen printers (if configured).

In case the order comes from a lane without a tab (e.g. tournament and league lanes), a new tab is created.

In the case the order printout has to be printed again, go to the new plugin under POS > Reprint > Reprint Orders. Here the order and the printer can be chosen.

If the Lane Orders have been chosen as urgent tasks for that terminal, the Quick Button starts blinking when there is a pending lane order to be checked. By clicking on it, a window opens, displaying all the urgent tasks that the terminal is subscribed to receive. The operator can click on the item they want to manage. When a task is already managed by another terminal, it is specified in the window.

When a terminal is in Safe Mode, the Tasks Requiring Immediate Attention window is displayed but it is read-only, so that the operator can see it but has to log in in order to process them.
