10.1 Creating an Item

To create an item, first choose the type of bowling Resource out of those available in the drop down menu in the Waiting List window.

Enter the Reference name (which will then be announced when it's time to play) and either press Enter on the keyboard to apply the primary Opening Mode or press the desired Opening Mode directly.

In either of the above instances, the Lane Control window opens with the left tab containing an hourglass and a label displaying the Reference .

As when opening a lane, all necessary data can be entered such as player names and options, default price keys can be modified, partial or complete payments can be taken and POS or Fast Sale Items can be sold.

The item is then added to the table in the waiting list, complete with data, whereby the receipt is then printed automatically if the Print Receipt option was selected.
