7. System

Hopewiser

Select which computer is the server for the Hopewiser application and enter the Port number.

BLS and BTM

Click here to open the standard window where the shared directory can be chosen, for the exchange of files between Conqueror and BLS and/or BTM.

Conqueror receives the tournament or league setup from the BLS (Bowling League Secretary) and BTM applications and uses it to open the lanes and start play.

The details of each finished game are automatically exported to this external application for further elaboration.

BES/QDac

In BES centers, insert the Server IP Address and the Lane Subnet Address .

In non-BES centers with TCS, enter the QDac Boot Server IP Address and the QDac Subnet Address .

R-Keeper

Define which computer is the server for the R-Keeper application and enter the Port number.

DSD

Click here to open the standard window in which the shared directory can be chosen for the exchange of files between Conqueror and DSD . Then set the frequency with which Conqueror is to receive information from the DSD application.

This reservation software works with Conqueror in commanding lane opening, closing and movements.

Zonal

Enables Conqueror to work with the Zonal application.

Conqueror works with this POS management software to manage the importation/exportation of data such as that regarding staff setup, users profiles & privileges, shifts, departments, price keys, taxes, discounts, etc.

After Zonal interface has been enabled, specify the time at which the data import from Zonal to Conqueror is to be performed.

At any moment, the Zonal import can be forced by pressing on the Force Update button.

Click on the Zonal Interface Path box to open the standard window where the directory can be chosen, through which files are exchanged between Conqueror and Zonal.

RecTrac

Click here to choose the shared directory to which financial data have to be exported for RecTrac accounting software.

Automatic Game Export Path

This option allows to automatically export games related to play events like a reservation, a tournament squad or a league week, to a .csv format file. The file is exported at lane closure and it contains lane data, player data, scores, handicaps, etc.

Select the related options (Leagues, Tournaments, Reservations and/or Open) and specify a directory to save the exported file in.

The name of the exported file contains a description of the play event followed by the export date/hour and is saved in the folder specified here.

Note that it is also possible to manually export a set of games through the Game Printouts module.

Number of Versions to Maintain

If a chain has an office that wants to connect to other centers (the office might be located in one of the centers), it can pass from one center to another without having to login again even if the centers have different software versions.

If managers have to connect to their own centers through remoting and the centers have different software versions, it is simply necessary to keep a link to each version on the desktop and launch the correct Conqueror when connecting to a center.

The number of version to maintain has to be included between 2 and 10.

Automatic New Version Download

With this feature, as soon as a new version is available on the QubicaAMF website, it is immediately and automatically downloaded onto the Internet Update computer.
