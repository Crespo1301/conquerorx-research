4.1 Adding Bowling Centers

In order to create and configure a new connection to a remote bowling center, press New and enter the following data:

Name

Enter the center name that will be displayed in the center icon on the Call Center window.

Color

Choose the color for the center icon.

Server IP Address

Enter the Conqueror Server IP address of the remote center.

Welcome Message

Enter the message that will be displayed to the Call Center operator during the connection to the remote center, e.g. a promotional message to be reported to the customer.

Authorization Required

This option restricts access to a remote center to only those Call Center operators with the required user privilege Connect to Authorization Required Centers .

Currently Available

This option enables/disables the connection to the remote center from the Call Center.

Not Available Because

The message entered here is shown when the Call Center operator selects a not-available remote center, and you can explain the reason the remote center is currently unavailable.

CALL CENTER > Call Center Setup > Adding Bowling Centers
