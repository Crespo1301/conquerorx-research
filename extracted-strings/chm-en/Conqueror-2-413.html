2. MMS Sequence Setup

Press Sequences to open the setting window.

Create a new sequence by pressing on + . Give it a name and start to build it.

Press + under the table, choose the first session to be displayed by clicking on the first table row and set its duration. Press + again to enter the second session and so on. These sessions will be displayed as a rotation sequence.

After having chosen the different sessions that compose the sequence, it is possible to re-order the sequence by using the up and down arrows, which moves the sessions up and down accordingly.

Create another sequence and press Save to send it to monitors.
