11.1 Local Payment Providers

PAYwareConnect Settings

Specify the Center Client ID and the URL .

Set the Pre-authorization Amount : when a credit card is necessary as guarantee to open the tab of a customer, it is possible to specify for which minimum amount a check to the customer's bank has to be made. Example: if a customer wants to open a tab in the Center and 1$ is set, the bank's server will be queried to find out if the customer has at least 1$ on their account. A tab will then be opened and payment can be made. In this case, set the Pre-authorization Amount to 1.

Now the PinPad Devices have to be installed in order to process payments. To install the center devices, go to Terminal Setup > Devices. In the PinPad Installed section it is possible to remove a device previously set.

PAYwarePC Settings

Specify the Center Client ID , User Name and Password , and the PAYwarePC Server Address and Port .

This payment mode can be used both on-line and in the local center.

If using PAYwarePC Debit Cards, a numerical PinPad is required to enter the personal identification number (PIN) needed to complete the transaction.

PCCharge Settings

Specify the Center Merchant ID , the corresponding Processor numbers and the PCCharge User Name , Server Address and Port .

Mercury Settings

Specify the Center Merchant ID and the Mercury Host List .

Set the Pre-authorization Amount : when a credit card is necessary as guarantee to open the tab of a customer, it is possible to specify for which minimum amount a check to the customer's bank has to be made. Example: if a customer wants to open a tab in the Center and 1$ is set, the bank's server will be queried to find out if the customer has at least 1$ on their account. A tab will then be opened and payment can be made. In this case, set the Pre-authorization Amount to 1.

If using Mercury Debit Cards, a numerical PinPad is required to enter the personal identification number (PIN) needed to complete the transaction.
