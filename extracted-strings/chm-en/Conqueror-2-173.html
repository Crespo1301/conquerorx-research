9. Shift Setup

Center Setup > Shifts Tab

Shifts

Select whether or not Shift management is desired.

If not selected, the system works in No Shift mode with Daily Reports.

Personal Cash Drawer

With the new Personal Cash Drawer management:

· The income of each operator must belong to a specific and personal cash drawer in order to be able to associate a specific cashier to a shortfall.
· Each cashier can collect money from different terminals by recording all movements in the same shift and in the same cash drawer (hardware or money pouch).
· Two cashiers can collect money from the same terminal, but in a specific, different hardware cash drawer.
· The access to the Personal Cash Drawer can be restricted to the connected cashier, but can also be accessed by others if they have the privilege to do so.

Enable the Personal Cash Drawer option in order to work with this new drawer management: the system checks if there are Shifts opened (not already printed), and then restarts.

When restarted with the Personal Cash Drawer management active, the Sectors & Cash Drawers tab is hidden and it is replaced by the new Cash Drawers tab.

Count Float on Closure

Select this option if the system is to propose counting the float upon Shift closure.

Bill and Coin Details

Select this option if the Moneys Received Summary window is to be proposed automatically when closing Shifts so that bills and coins from the float can be counted into the system.

Stricter Under/over Management

It is possible to set an under/over limit for each cash drawer. At shift closure, if the under/over is beyond the limit, the operator has to enter a note. These justificatory notes are then reported in the Shift reports.

Enable this option then go to Setup > Center Setup > Sectors and Cash Drawers in order to set the single cash drawer limits.

Notes, Weather and Staff

With this option, the system automatically proposes the Notes, Weather and Staff window upon Shift closure.

Float Confirmation

Select this option to confirm the float amount upon Shift closure.

Shift Report Signing Section

Select to include the Confirmed by Supervisor section, where the cashier and manager can sign the report.

Automatic Shift Closure

For Centers that use the system of automatic exporting for the moneys received each day, this option checks if any cash drawer sessions or Shifts remained open at the day change time, and automatically closes them.

In Centers located in France, this option is activated by default in order to prevent any fraudulent intervention.

Print Function

Choose the archive operation desired for the Shift from: Print , E-mail , Export , Nothing .

If e-mail is chosen, specify the address on the right, to which the report will be sent.

Automatic Export

Select the external accounting program, such as QCad, to which the shift data is exported upon Shift closure.

Select the QuickBooks Desktop check underneath to add the QuickBooks Desktop and Both options to the Automatic Export scroll menu.

Tax Exemption Suffix

Configure the tax-exempt suffix for Dassle export.

That suffix will be appended to price key information during export when the price key is sold with tax-exemption.

QuickBooks Desktop

Select whether the QuickBooks Desktop management software is to be used.

With this option selected, the Export Detail Level scroll menu can be accessed, in which the default level of detail can be selected for data exportation.

Press Setup to access the QuickBooks Desktop account settings.

Reset Shift Report Number

Choose whether the number of the Shift report gets reset Every Day or Never .

Backtask Sector

It is advisable to create a "virtual" Sector that will be utilized by Conqueror's Backtask (especially when working with the Booking System), where transactions such as automatic cancellations of bookings with deposits paid, are registered.

Send Report

Specify the e-mail addresses to which the reports have to be sent in the case the archive operation desired is set on e-mail.

This is useful when the manager has more than one Bowling Center to run, or is away from the premises and wishes to check on things.

Shift Zone

Press this option to access the Define Shift Report Time Zones window.

Here the bowling day can be divided into various Time Zones (e.g. morning, evening and night) giving them a name, so that in the data in the reports is grouped into these sections.

The Group by Time Zone option will be activated for the End of Shift Report.
