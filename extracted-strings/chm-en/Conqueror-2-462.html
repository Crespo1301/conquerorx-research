9. Intercom

BES, Bowland and Bowland-X Only

The Intercom is the system of communication between lane and front desk, whereby a mini speaker is present on the lanes and either a mini-speaker or a telephone is present at the front desk and at the mechanic's desk.

The customer makes the call by pressing the intercom button with the speaker on the console whereby the telephone rings at the front desk and the Intercom icon is present in the Lane Status window. If the front desk phone is busy, the calls are queued according to the order in which they were placed unless the Cancel Call if Busy option is selected.

The Intercom settings window displays the settings for a specific QDac per page, the arrows at the top of the screen can be used to scroll through the various QDac setting tabs.

The Intercom Settings privilege is necessary to modify these values.

Press New to define the settings for a new QDac, Delete to cancel the settings pertaining to a QDac and Reboot to reset the QDac. Press Save if the settings are to be saved but not necessarily sent to the QDac.

Description

By pressing New the QDac number is automatically entered here.

Serial Number

Enter the serial number pertaining to the QDac, which can be read on the QDac label.

Status

The QDac status refers to the network connection between the QDac and the Conqueror terminal.

Before being correctly configured, the status is set as Unknown . After the settings are saved and the QDac rebooted, the QDac status is displayed as Connected or Disconnected .

Number

The QDac number is entered here in order to identify all telephones and speakers connected to it.

By default, telephones always start with the number 300 and speakers with the number 200, so if the number 1 is entered here, the corresponding telephone will be numbered 301 or the speaker will be 201.

The arrows can be used to scroll through the numbers from 1 to 9.

Inter-Hub

Bowland Only

Check this option if the QDac uses the Intercom Hub as interface to the lanes.

Lanes

Bowland Only

This field displays the range of lanes connected to this QDac through the Intercom Hub interface.

Speaker

Check this option if a booster amplifier unit is used at the front desk/technician's station.

Exponential Dynamics

Bowland Only

Enable to enhance the communication to the console.

Phone

Check if a Q-Phone Plus telephone is connected at the front desk/technician's station.

Phone Commutation Threshold

This value sets the sensibility of the Q-Phone Plus microphone to noise, that is the level at which the Intercom switches to the QDac as speaker, as a response to noise at that end.

For noisy Centers it is recommended to set a high level for this setting, the suggested value for a standard installation being 75.

Lane Recall Pause

Set the length of the pause (in seconds) between a call and another, giving the operator time to satisfy the previous request.

Stop Ring after

Enter the number of seconds after which the phone is to stop ringing if no-one responds.

Set 0 here if the phone is to ring for an unlimited amount of time.

Phone Lanes

Enter the range of lanes that directly calls the QDac.

Cancel Call if Busy

Check this option if the call is to be cancelled if the line is busy upon the first attempt. If this option is checked, the call is not placed in the queue.

Phone Sensitivity Threshold

Enter the time during which the system analyzes the sound on the Q-Phone Plus side. It is used to switch the direction of the communication and works only with the automatic mode. The threshold can be set at a value between 0 (the shortest time) and 19 (the longest time). The higher the threshold value, the longer the lag between the actual speaking on the Q-Phone Plus side and the hearing on the console side. The suggested value is 5.

Lane Number Communication

Enable here the voice message that communicates the lane number to the operator before the bowler starts speaking.
