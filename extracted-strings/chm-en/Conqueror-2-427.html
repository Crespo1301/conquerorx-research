1. Web Reservations

Setup > Web Setup > Web Reservations

Before using the Booking Website, it is necessary to set at least 1 Web Scenario .

A reservation scenario is a web reservation type and it is made up of a name, a personalized picture, a Deposit value, a Reservation Type , a brief Description and price keys.
