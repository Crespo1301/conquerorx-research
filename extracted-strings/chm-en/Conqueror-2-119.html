17. Redemption Ticket Management

Setup > Bowling Setup > Redemption Tickets

To create a new configuration set for redemption press Add , enter a Name and then specify how many tickets have to be given to the player through the ticket dispenser for each score or in case of Special Game win.

Thanks to the Double Tickets Starting from ... option, it is possible to give double tickets after a certain number of games have been played. By entering 3 in this field, bowlers playing 4 games will receive double tickets during the 3rd and the 4th.

When a number of tickets is associated to each score, press Save .

Redundant configuration sets can be deleted only if not linked to any Lane Option set.
