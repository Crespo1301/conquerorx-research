1.1 Reservation Scenarios

To create a scenario press New , enter the Scenario settings as described below and press Save .

Name/Picture/Description

Give the scenario a name that will be displayed at the top of the scenario square.

Choose a Picture to illustrate the scenario and type a short Description that will be displayed next to the picture.

To load one of the default pictures already present in the system, click on the folder icon and choose the desired picture. The folder that opens is in the following directory: QDesk\Graphics\Web\Scenarios.

To load other (customized) pictures, save them on the computer and proceed as above. Please note that they must be in .bmp, .gif, .jpg, .jpeg or .png format. The maximum size must be: width 133 x height 100 pixels.

Reservation Type

Choose the Reservation Type to associate to the current scenario.

The Reservation Types available in the scroll down menu are those set previously in Center Setup > Reservations.

Tag

This option allows to enter one or more tags helping to categorize scenarios in different groups.

Please refer to the Center's webmaster in order to manage scenario tags.

Number of Players

Set the minimum and the maximum number of players for the scenario.

Allow Web Customer Note

Enable this option to display a free space where the web customer can enter a note. This note will be reported in the Reservation Details.

Extended Availability

It is now possible to specify for each individual web scenario when the Extended Availability feature is to be used. E.g. when a scenario is dedicated to a single event (such as for the Halloween weekend), the center may wish to disable the Extended Availability in order to avoid displaying an almost empty grid.

Deposit

Here it is possible to set the deposit the web customer has to pay by credit card to confirm their reservation.

The deposit can be either a Percentage of the total reservation due or a Fixed amount: select the deposit type and specify the desired values. To allow reservation without any deposit, check the No Deposit option.

Booking Restrictions

Specify time limits in which web customers are allowed to book. For example it is possible to set that:

  • It is not possible to book less than [2] [hours] before playing
  • It is not possible to book more than [3] [years] before playing

Validity Dates

This option allows creating web reservation scenarios dedicated to an event or a certain period (e.g. the holiday season, summer holidays) etc.

The scenario is available to be booked as soon as it has been created, but can be booked only for a date included in the range specified here.

E.g. It is possible to book between December 20, 2013 and January 6, 2014.

Note for Web Customers

Enter a memo for the scenario, which will be displayed above the customer requirements and highlighted in boldface type in the reservation confirmation window.

Lane Groups

Define the lane set dedicated to this Reservation Scenario.

E.g. Associate the birthday parties scenario to the lanes near the party rooms.

Linking Price Keys to the Scenario

Now the scenario is created and it is necessary to associate price keys to it.

The scenario price keys will be displayed in the Experience window of the website and the customer will be able to choose the one they prefer.

To associate price keys to the scenario, click on the scenario on the left-hand side and press Price Keys : the whole price key structure opens and it is possible to choose all the price keys to associate to the scenario.

Click on a department to display its price keys, then select the price keys to be assigned to the scenario and press the assign arrow. Similarly, to remove a previously chosen price key, select it and press the remove arrow.

It is possible to use the multiple selection of price keys by pressing the Ctrl key on the keyboard.

After choosing the scenario price keys press OK and save.

At least one price key must be associated to the scenario in order to have it displayed on the website.

Customizing Web Price Keys

To enter the web settings for each price key, click on a row/price key and press Modify .

In the window that opens it is possible to:

  • modify the web price key name
  • enter a short Description
  • choose a Picture to illustrate the price key. Click on the folder icon and load a picture in .bmp, .gif, .jpg, .jpeg or .png format (the maximum size must be: width 60 x height 60 pixels)
  • specify the Number of Bowlers for whom this price key is valid
  • manage the Include in Best Price option: enable it for the price keys to be used in the calculation of the best price shown in the Date and Time page of the website, when the Extended Availability feature is used.

Scenario Display Order

The various scenarios will be displayed on the website in the same order they are displayed in this window.

Use the blue arrows to move the scenario up and down.

Managing Add-ons

Non-bowling price keys (e.g. Food and Beverage items) can be sold to web customers.

Press Add-ons to manage these price keys, in particular to categorize them in order to make the search and selection easier for the web customer.

To create a category, press New , give the new category a name and press OK .

The various categories will be displayed on the website in the same order they are displayed in this list. Press the blue arrows to move the category up and down as desired.

Select the category to be filled in and press Price Keys .

In the window that opens click on a department to display its price keys, then select the price keys to be assigned to the category and press the assign arrow. Similarly, to remove a previously chosen price key, select it and press the remove arrow.

It is possible to use the multiple selection of price keys by pressing the Ctrl key on the keyboard.

After choosing the price keys that make up the category, press OK and save.

The price keys chosen will be displayed in the website add-on page in the order they are displayed in this column of this window. Press the blue arrows to move the price keys up and down as desired.

To customize the price key display for the web, click on a price key in the right-hand column and press Modify .

In the window that opens it is possible to enter a customized display name and to choose a Picture to illustrate the price key: click on the folder icon and load a picture in .bmp, .gif, .jpg, .jpeg or .png format (the maximum size must be: width 60 x height 60 pixels).

Enter a Promotional Message for the web customers that will be displayed on the add-on page.
