12.3 Customizable POS Layout

Setup > Price Setup > POS Setup

The Sales window layout can be customized, defining the specific location of each single price key at center level. Furthermore, groups of price keys can be formed and highlighted with separator spaces.

This feature allows operators to quickly distinguish the price keys to select, making the Sales window easier to use and the sales operation faster.

To access the POS layout customization, first enable the Use Customized POS Layout option and then press POS Layout : on the left-hand side of the window, the tree structure represents the categories as they have been organized in the Category Setup module. Click on the first category to be customized to visualize the current price key display: now price keys can be moved.

Moving Price Keys

It is possible to modify the existing display order by simply using the drag & drop method on each single price key.

The alternative is to start from scratch, putting all the price keys momentarily in a stack in the central column and then by placing the price keys into position one by one as desired. To do so, click on Remove All and use the drag and drop method.

If the operation is saved before all the price keys are placed into the desired position, the price keys left in the stack will automatically be placed by the system after all the other price keys, in the same order they are displayed in the central column.

To automatically place all the price keys present in the central column into the layout, use the Add All function. The display order will be respected.

Forming Groups of Price Keys

In order to form and highlight groups of price keys, place separator spaces before and after the group.

To do this, click before the price key where the space has to be placed and click on Add Space . To remove a space, click on it and use Remove Space .

When selecting a price key, its validity details (Price Applicability Dates) are displayed in a dedicated space above the button panel.
