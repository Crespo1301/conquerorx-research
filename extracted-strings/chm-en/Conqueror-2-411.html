1.5 Advertising Playlists

Press Advertising to enter the advertising session setup and create playlist composed by pictures and/or videos. Different playlists can be prepared in advance (e.g. seasonal or event related playlists) but marked as Active only when needed.

Press + under the Available Images and Videos in order to load pictures and/or videos from the computer.

Managing Playlists

To manage the Playlists , use the buttons in the upper right-hand corner of the window. Here you can create new playlist, rename or delete an existing playlist.

Choose a playlist in the scroll down menu or create a new one by pressing on + .

Use Insert button to move the media in the currently selected Playlist . In the Playlist column, give the media a specific display order with the up and down arrows.

Set the number of seconds pictures have to stay on the screen (Picture Display Time ) and press OK to save the playlist.

Only Active playlists are available to be assigned to lanes, so activate the relevant playlists with the Active option. The activated playlists cannot exceed 4 Gb, as displayed in the Active Playlists bar.

To reset a playlist, press Empty .

Recommended Formats

The pictures loaded should be 1280x720 pixels; if the pictures are smaller or bigger, they will be automatically adjusted.

The videos loaded should respect the following characteristics:

  • Video Container : MP4, MOV, M4A, 3GP, 3G2, MJ2, AVI, MPEG, ASF
  • Video Codec : H.264, MPEG-2 Video, VC1, WMV2, WMV3
  • Video Bit Rate : 4.000.000 bps
  • Video Resolution : 1280x720 pixel
  • Audio Codec : AAC, WMA v1, WMA v2, MP3, MP2, DV
  • Audio Bit Rate : 160000 bps
  • Audio Sampling Rate : 44100 Hz
  • Audio Channels : 2 (stereo)

Other Supported Formats

PowerPoint presentations can be displayed by converting the presentation into a video file using a commercially available software tool, not provided by QubicaAMF, such as "Leawo© PowerPoint to Video Pro".

Conversion Warning

Videos loaded are converted by Conqueror Pro in order to be correctly displayed on the MMS monitors.

Converted videos have the following characteristics:

  • Container: MP4 - Video codec: H-264 - Video bitrate: 4.000.000 bps - Video resolution: 1280x720 pixel
  • Audio Codec: AAC - Audio bitrate: 160000 bps - Audio sampling rate: 44100 Hz - Audio channels: 2 (stereo)

If an error occurs during the conversion procedures, a window opens displaying the error details.

In the case of conversion error, we provide a video converter to be used on a Windows 7 computer connected to the web, which is located in the Video Converter directory on the Misc folder of the Installation CD1. Move this directory and the video to be converted on a Windows 7 computer, launch Setup.exe and when the video is converted, load it on the Advertising module.

If a Conqueror terminal of the center runs on Windows 7, load the video from this terminal. If you don't have any Windows 7 computer available, use a video converter of your own choice and respect the video characteristics listed above.
