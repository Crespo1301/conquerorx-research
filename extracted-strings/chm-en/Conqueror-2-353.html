4. Quick Authorization

Center and duty managers can authorize an employee to carry out a protected action (once), without leaving their work session.

If an operator needs to carry out an action, but they do not have the necessary user privilege, the system proposes the operator to be authorized by another operator having the specific privilege. The operator with the requested user privilege has to identify themself to temporarily "lend" the operator that ability; this is done either through fingerprint recognition, swiping the personal card or inserting the User Name and Password in the Log on panel.

E.g.: an operator needs to carry out a refund and the system requires the manager's authorization. By touching the fingerprint scanner or swiping their personal card, the manager temporarily gives the operator their ability to refund.

For security purposes, every time an operator gives Quick Authorization , the event is registered in the System Log as a Suspect Action.
