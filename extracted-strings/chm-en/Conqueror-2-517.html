6.5 Ordering Modifiers

This function is particularly important to set the best display order for the modifier groups, when related to a package that could contain more than one item requiring modifiers.

Press Ordering to access the window allowing to customize the modifier display order for each single price key (e.g. for a hamburger, put the cooking type first, then the additional sauces).

Use the arrows to put the modifier groups in the desired order. To apply the change to a group of price keys having the same modifier groups, select them before putting the groups in order.

ECONOMIC SETUP > Modifiers > Ordering Modifiers
