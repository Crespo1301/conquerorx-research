2.3 Selling Beverages through Dispenser

To sell a beverage through the dispenser, open the Sales window in a Food & Beverage department and enter the related code on the dispenser keypad: the beverage is automatically added to the bill currently open.

To pour beverages through the gun system and manage these sales in Conqueror Pro, it is necessary to:

      1. set the device and its port in the Terminal Setup,
      2. associate codes to the beverage price keys,
      3. configure the dispenser accordingly (carried out by a qualified technician).
In case of dispenser damage or disconnection it is possible to use the price keys as regular price keys.

A single Berg dispenser can be shared by two (or more) different Conqueror Pro terminals by connecting a specific Berg switch to the Berg keypad and to the Conqueror terminals. The operator can use it to send the entered Berg code to all the connected Conqueror Pro terminals.

In the Price Key Setup it is necessary to:

  • duplicate the price keys that are used by more than one Berg dispenser,
  • assign different codes to the duplicated price keys,
  • specify, for each price key, which code is valid on which terminal.
Voiding a transaction row related to the beverage dispenser is considered a Suspect Action and is therefore reported in the Shift Reports.
