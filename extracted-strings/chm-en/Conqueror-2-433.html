1.6 Extended Availability

Through this window it is possible to display to the web customers the price trend in a range of 4 weeks, modifying the display of the Date and Time page of the website: instead of the classic page, a chart is shown, divided horizontally in 4 time zones (morning, afternoon, evening, night) and vertically in 4 weeks (the current one and the next 3 weeks).

Each cell contains the best price for this time zone and for this week.

The Best Price shown is the lowest among all the price keys with the Best Prices option enabled, and it follows the rules set on the Dynamic Pricing page.

In the Promotions space, enter the message to be displayed under the price chart, giving an indication to the web customers about the current promotions available.

If this feature is enabled at center level, it will be possible to disable it in each Web Scenario configuration window. If Extended Availability is disabled at center level, it will be disabled for all web scenarios as well.

WEB SETUP > Web Reservations > Extended Availability
