21. Lane Options - AccuScore Plus

Bowler Keyboard

If disabled, bowlers cannot use the Next Game function, substitute bowlers from keyboard and modify bowler name and games. If a tournament is taking place and only the tournament director is allowed to carry out modifications, this option has to be disabled so players cannot control the keyboard.

Enabled by default.

Next Game Key during Game

Enable to allow bowlers to use the Next Game function from the keyboard. The game currently being played will be interrupted and the new game will start.

Paging/Speaker

Activates the speaker in the overhead monitor. Disabled by default.

Lane Viewer

Enable bowlers to view another lane's score from their lane.

Graphics

By enabling this option, graphics are displayed on lane monitors when a player scores a Strike , a Spare , a Split , etc.

Pindication

Enables a fixed image on the monitors that shows the throw and the number of pins still standing.

Spare Maker

Displays the bowl necessary to achieve a Spare.

Print Score after Closure

Enable this option if the scores are to be printed automatically upon lane closure.

When opening lanes in the case of a tournament squad or a league week, a message warns that this option is enabled, so the operator can choose to confirm the printout or to disable it in order to save paper.

The score sheets are printed by the printer specified in the Terminal Setup.

Baker

Through the Baker option, the first frame of the game is played by the first player, the second frame of the same game by the second player and so on.

Classic Game

This option allows to set one of the Classic Games.

  • 3-6-9 : the 3rd, 6th and 9th frames are not played because three Strikes are automatically assigned to players.
  • No Tap : if the first bowl in the frame scores 8 or more (8 Pin No Tap ) or 9 or more (9 Pin No Tap ), it is automatically converted into a Strike.

Swap Lanes

Available configurations:

  • after every frame: Alternating
  • never: No Alternating
  • after every game: Alternating after Game
  • League Extensions : the differences from the normal alternating mode are:
    • bowlers can change the team name
    • bowlers can erase frames
    • it is not possible to bowl without names
    • it is possible to set practice, which means bowling without arrows and without keeping scores
    • the maximum number of bowlers on the lane is 5, but the roster can include up to 10 players (5 regular players and 5 team substitutes to choose from on the lane)

Display Type

It is possible to choose how to display the score on the lanes between: 10 frames , 5 frames and Tournament format.

Score Color Sequence

This option allows the user to change the color of the grid and of the whole background of the screen at the beginning of each game. Choose a color for the first game, the second game and the third game; after the third game, the color sequence restarts with the first color.

Practice

In the case of an "alternating" league, practice can be:

  • On with Pins
  • On without Pins
  • Off

Practice Time

Set practice duration in minutes.
