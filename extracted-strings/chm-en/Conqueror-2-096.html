10.6 SMS Notifications

It is now possible to send SMS messages to customers present in the Waiting List in order to advise bowlers when the lane or time game becomes available.

To use SMS notifications in the Waiting List, it is necessary to configure Conqueror and the Bowling Center Twilio account.

Conqueror Pro Settings

Go to Setup > Center Setup, select the Lane Control tab and click on the SMS button. The SMS Notification Setup dialog opens.

SMS Notifications

The first checkbox enables the SMS messaging system.

When disabled, no window appears to ask for the customer phone number when a new Waiting List item is inserted.

Default International Code

Insert the Default International Code, e.g. "1" for the US".

When sending the SMS, this code is entered by default, but can be overwritten if necessary.

Messages

Three notifications have to be entered for each Resource type in the center (e.g. bowling and time games): select a resource type from the drop-down menu, enter the messages and then select the next resource type.

· Welcome SMS : send the welcome message; or resend it if the customer did not receive the original message for some reason, e.g. an incorrect phone number was inserted.

· Notification SMS : notifies the customer that the lane is ready;

· Alert SMS : this is the "last call" message that informs the customer that they will lose their priority in the Waiting List if they do not arrive soon after having already been notified about their lane availability.

To disable all SMS notifications for a single resource, all messages for that resource must be left blank.

Twilio Setup

After registering on Twilio, it is necessary to insert the proper Account Sid , Auth Token and Phone Number in the related tab.

Click on Save to store the settings.

Inserting a New Item in the Waiting List

When a new item is added to the Waiting List, the SMS Sender dialog appears for inserting the customer telephone number. If a number is entered, then the pre-configured Welcome SMS can be sent to the customer by clicking on Send. Then, this phone number is saved in order to be used for the Notification SMS and then for the Alert SMS. The Default International Code is the one inserted as default but can be overwritten if necessary. The prefix (e.g. "347") is saved too and is entered by default for the further customer. Press Cancel in order to save the Waiting List item without connecting a phone number. If the SMS Welcome field was left empty in the SMS Message Setup dialog, the Send button turns to Save: the Waiting List item is saved without sending any Welcome SMS.

Sending Notifications and Modifying Item Details

Bowling Item Details

In the Waiting list module, select a bowling item and click on Details to open the Waiting List item details dialog. From here it is possible to send SMS notifications to the customer and also modify the associated phone number. Each message can be sent multiple times and the number of times that the messages have already been sent is shown below each button as shown in the picture. The SMS notification buttons are enabled if the corresponding SMS message has been defined in the SMS Message Setup dialog and the phone number field is not empty. After a notification button is pressed, Conqueror asks for confirmation to send the SMS; click on Yes to proceed and save any changes that have been made. In the Waiting List item dialog, it is also possible to change the Reference person for the Waiting List item, add Notes and modify the Phone number. If any changes are made, the Save and Undo buttons are enabled. Clicking on the Save button will store the modifications, while clicking on the Undo button causes the changes to be lost. The arrow buttons allow operators to move between items in the Waiting List. If the operator attempts to close the Waiting List item details dialog or use the arrow buttons to move between items, and some changes have been made, Conqueror will request confirmation from the operator before proceeding. Clicking on the Save button stores the modifications and ends the selected task, while clicking on the Do not save button causes the pending changes to be lost.

Time Game Details

In the case of a Time Game item, the details dialog only shows the SMS notification functions. These functions (SMS notification buttons, phone number field and navigation arrows) are the same as for Waiting List items.

Waiting List Display

How the Information is Displayed in the Waiting List

The Waiting List now includes new columns showing the SMS details of the items in the list. Three new columns have been added with the following information:

- Tel. shows whether the customer has provided a phone number.

- Notified shows if the customer has been already notified with the first Notification message. This column shows the time when the last Notification message has been sent. If the Notification messages are more than one, a number of sent messages will be displayed.

- Alerted shows if the customer has been already notified with an Alert message. This column shows the time when the last Alert message has been sent. If the Alert messages are more than one, a number of sent messages will be displayed.
