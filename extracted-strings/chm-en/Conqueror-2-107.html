15.3 Advanced

Pinsetter on with Sign-in Screen

Enables the starting of the pinsetter during the insertion of player names on the lane keyboard.

This option is deactivated by default with the pinsetter off during name insertion thus saving electricity: in which case the pinsetters are activated by pressing the Red Key when the customers are ready to play (i.e. after they have changed their shoes and entered their names).

Begin Practice When First Ball is Thrown

If this option remains selected (as by default), practice time starts from the moment the first ball is bowled.

Deselect this option if the practice time is to start from the moment the lane is opened from the front desk.

This option is available only when the practice is measured in time and not by the number of bowls.

Warning Message

Enable here to display the Warning Message prior to lane opening.

When the message is displayed on the lane, bowlers have to acknowledge it to open the lane.

In BES X and Bowland-X Centers, this message is customizable and translatable in the Center Setup.

Print Score after Closure

Enable this option if the scores are to be printed automatically upon lane closure.

When opening lanes in the case of a tournament squad or a league week, a message warns that this option is enabled, so the operator can choose to confirm the printout or to disable it in order to save paper.

The score sheets are printed by the printer specified in the Terminal Setup.

Stop Game

BES only

Activates the Stop key on the lane keyboard.

Start new game from sign-in

Allows players to start a new game from sign-in.

Start New Game

Allows players to start a new game by using the SuperTouch device even if the current game is not yet over.

Close Lane from console

Allows players to close the lane from the SuperTouch.

Score Correction

This enables players to correct their scores using the lane keyboard.

By enabling this option in a BES Center, the Delete Throw option is automatically activated as well.

By enabling this option in a Bowland Center, the Disable Delete Bowl option is automatically activated as well.

Delete Throw

BES and BES X Only

This enables players to delete the last two bowls using the lane keyboard.

This option is available only if the Score Correction option is enabled.

Your Lane Your Way

BES Only

This allows bowlers to choose/modify the on-lane environment.

Foul Input Check

This option is only visible if the Advanced Foul Device has not been set in the Center Setup.

Activates the electronic device that makes sure that the players don't exceed the foul line.

If the foul line is surpassed, the foul symbol is displayed in the player's score.

Light setting

This option is set by default on the Bowling Mode choice; this means that the options selected in the active Bowling Mode will be applied to that lane.

By clicking in the field, it will be open a window where deciding a custom color for the open lane light.

The Enable Event Light Effects option activates colored LED flashes during the welcome and the warning messages and game events (Strike, Spare etc.).

Pressing OK in the LED Color Effec t box, the color selected will be displayed.

Picture Validation

BES X Only

Enable here the Picture Validation for the photos taken from the SuperTouch console on the lanes.

Speed Limit

Set the limit, above which the speed of the bowl is no longer displayed on the monitor and the counter must be reset at the front desk.

This deters players from competing for the fastest bowl, as throwing as fast as possible is dangerous and could cause damage.

Hyper Speed Limit

It sets Hyper Speed Limit range.

Advanced Foul Mode

This option is only visible if Advanced Foul Device has been set in the Center Setup.

Three different states can be managed from Conqueror:

  • Off
  • On (if the foul line is surpassed, an alarm sounds and the foul symbol is displayed in the player's score)
  • Warning Only (the foul line is passed, only the sound alert is activated, with no effect on the score)

Game Eligibility

Set the games played as For the Center Average or not, or Official Games . This option can be modified after the event has been played in the Game Printouts module.

Club

Choose the minimum final score (between 175, 200, 225, 250, 275, 300) for which to have animation displayed on the lane monitor.

When players reach the points set here, the monitor displays an animation like "Club 200"!

For five-pin bowling it is possible to choose between 200, 250, 300, 350, 400 and 450.

Slow Bowling

Select the number of minutes that bowling can lapse before the front desk is alerted and animation is displayed on the lane monitor requesting the bowlers to recommence play.

Walk Down Time

Set the amount of time it usually takes for bowlers from the moment their lane is opened at the front desk, to when they are present and ready for play on the lanes.

For example if a lane is opened for a group at 3:30 pm for an hour's play, and Walk Down Time is set at 2 minutes, the hour of play will commence at 3:32 pm.

Choose between 1 and 14 minutes, Off if not wishing to use the setting (such as when opening lanes through game mode), Unlimited if not defining the amount of time, commencing the time from the moment the lane is opened.

Walk down time finishes as soon as the first ball is bowled.

Upper and Lower Monitor Mode

BES Only

Select the layout for the lane monitor grid from the following:

  • Default - normal layout with each lane on its own monitor
  • 12 Player Mode - when there are more than six players to a lane, by setting this mode, the player rows shrink to allow for more players
  • Score Grid Share Mode - if two lanes are open, the data of both lanes can be displayed on one screen, leaving the other free to watch television or advertisements and the like
  • Super Wide - Spread one lane's image across both monitors in a pair for a super-wide view. This permits the score display of one lane to be spread out over two monitors, that is, the first five frames on the left monitor and the second five on the right.
  • Super Wide Share - spread two lanes across the pair. This permits the score display of two lanes to be spread out over two monitors, that is, the first five frames on the left monitor and the second five on the right.
Pip TV - this option displays the television in the right-hand corner of the monitor (not available for 3QT hardware) .

Welcome Screen

Option available only for SuperTouch, if the Touch screen/Keyboard option is enabled.

Click to open the Welcome Screen setup.

From the Preview for scroll down menu it is possible to choose the type of Welcome Screen between:

  • Open
  • Reservation
  • League/Tournament

When opening, the preview of the standard default Welcome Screen is displayed (blue background).

All the types contain the lane number on the left and the welcome courtesy sentence (title) on the top: Welcome to [center name].

On the right:

  • For the Open type, the player names are displayed. In the case of opening without specifying the player names, it will be displayed the number of players (e.g. "3 players"),
  • For the Reservation type, the reservation name is displayed in red with the number of players,
  • For the League/Tournament type, the league/tournament name is displayed along with the week number, the team is displayed in red with the player names below.

To customize the Welcome Screen, it is possible to:

  • modify the title, writing in the two lines on the bottom left (press the refresh button to update the preview);
  • choose an image by clicking in the Background list on the right; immediately the preview will be update;

To add an image, click on the + button on the right of the Background list. To remove an image click on rubber button.

Please note that the perfect size for the picture is 1280*720.

Clicking on the OK button, the Welcome Screen defined will be saved and in the Advanced tab of Lane Options module the Welcome Screen box will display the name of the custom picture selected as background.

To remove the custom Welcome Screen defined click on "X" and the standard default style Welcome Screen will be displayed during lane opening.

When the lane associated to open bowling, reservation or league/tournament will be opened, the saved Welcome Screen will be displayed on the lane monitors and on the SuperTouch (if present).
