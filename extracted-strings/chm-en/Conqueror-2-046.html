9.2 Tax-exempt ID Linked to FB

For each FB it is possible to insert a Tax-exempt ID.

If a tab is linked to a FB with a Tax-exempt ID, when the FB pays the tab, the system automatically uses the Tax-exempt ID to calculate the tab payment total with tax exemption.

Reservations

If a reservation is linked to a FB that has a Tax-exempt ID, the amount of the deposit is automatically recalculated using the total without taxes.

When the FB pays the reservation, the system automatically uses the Tax-exempt ID to complete the reservation payment with tax exemption.

Web Reservations

When web user are registered with a Tax-exempt ID, the amount of the deposit of their web reservations is automatically calculated using the total without taxes and their Tax-exemption ID is used when paying the reservation.

The Tax-exempt ID is not saved into the tab, so in the case the operator doesn't proceed with payment, the tax-exemption ID is deleted; it has to be entered again when the customer pays the tab.
