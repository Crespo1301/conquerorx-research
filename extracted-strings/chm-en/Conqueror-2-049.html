10. Credit Card Transactions

Back Office > Credit/Debit Cards

This module contains a summary of all credit card and debit card transactions performed throughout the day.

The Type column shows the label Debit or the Credit Card provider name to identify the transaction type.

Web Transactions and Local Transactions are displayed separately. To switch from Local transactions to Web transactions, use the button Web/Local in the control panel. The control panel, the Close Batch feature and the Summary regard the table currently selected.

In the table it is possible to verify the status of all transactions, reprint receipts, filter the transactions displayed and void credit card transactions (if selecting a debit card transaction, the Void button is disabled).

In this summary one transaction is displayed per each line and automatically updated as its status evolves.

The ID (number associated to the transaction), the Date the transaction was performed and the transaction Status are specified for each line (for each transaction) as follows:

  • Executed : the request has been sent to the bank (or to the international circuit), but the financial transaction is still open, so the operation can still be voided.
  • Voided : the operator has voided the transaction due to an error.
  • Closed : the bank has confirmed the operation, the transaction has been executed and therefore can no longer be voided.

Then, the Total amount of the financial transaction paid by credit card is indicated, followed by the Tip amount paid, the masked Card Number , by the Operator who performed the transaction and the Authorization Number given by the provider.

If the transaction is voided, also the Void Date will be specified, while the name of the operator responsible of the void operation will be indicated in the Voided By column.

From...To...

This option allows the operator to view all transactions performed in the specific period of time entered.

Reprint

This option reprints a copy of the receipt pertaining to the selected transaction.

Void

This option allows voiding the selected credit card transaction.

Refresh

This option refreshes the list displaying all recent modifications, such as new transactions or changes of status made after screen opening or after the most recent refresh.

Web or Local

Web Transactions and Local transactions are displayed separately. To switch from Local transactions to Web transactions, use the button Web/Local in the control panel. The control panel, the Close Batch feature and the Summary regard the table currently selected.
