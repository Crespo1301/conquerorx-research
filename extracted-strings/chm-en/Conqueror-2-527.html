10.1 Settings

Setup > Price Setup > Denominations

Here Notes , Coins and Special Payments (such as credit cards, vouchers, cheques, etc.) can be inserted.

The window opens with the main currency of the Bowling Center selected.

To enter a coin, click in the Coins column, press New and enter the denomination Description (e.g. "quarter of a Dollar") and its Value ("$ 0.25"). Repeat this operation for all denominations.

After putting in all the denominations of the main currency, press the Currency button, select a different currency in the list and enter a new set of Notes , Coins and Special Payments .

To modify a denomination already present, select it in the columns and press Modify .

Special Payment Settings

To enter a Special Payment (such as QCash, Credit Card, Prepaid Cards, etc.), click in the third column, press New and:

  • enter the payment mode Description (that is a free choice)
  • if working with a third party program, set the relevant External Key
  • select the related Payment Type (QCash, Credit Card, Prepaid Card, Debit Card, Member Account, etc.)
  • enable the Authorization Required option to limit the use of the current payment mode only to operators with the required Access 'Authorization Required' payment modes privilege.
  • if enabling the Display Total in Money Summary , the total related to the Special Payment is automatically calculated and displayed when closing shift, in the Money Received Summary .

For Special Payments set as Undefined , it is also possible to predefine more that 1 default value, in order to make the payment procedure quicker. In case of coupons, for example, it is possible to set coupons of 5$, 10$ and 15$. In the Payment window, when choosing the Coupon payment mode, a little window opens displaying the 3 different values allowing to quickly enter the quantity of coupons received. To set the payment mode default values, click on Default Values field, enter the first value, press + , then enter the second value, etc.

The order of the Special Payments in the column is also the display order in the Payment window; use the arrows to customize it.
