12.2 Prepaid Cards

CoinTech, Embed, Intercard, Sacoa

Enable Conqueror Pro to work with the third party prepaid card application, then define which computer is the server for this application and enter the port number.

If working with Embed, enter the same User Name and Password used previously on Embed server .

If working with CoinTech, enter the specific Separator , the Prefix Length and the Suffix Length .

These settings are set during the installation of the third party system. It is not recommended that operators modify any of these settings without first having received instructions from a qualified technician.

To visualize the third party application as a Special Payment in the Payment window it is necessary to create the relevant payment mode in the Denomination Setup.

POINT OF SALE > POS Setup > Prepaid Cards
