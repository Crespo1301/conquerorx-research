2. Special Game Types

2.1 Bowlin'Hood

Aim of the game is to center a target according to the logic of archery.

The season changes at new game start.

The "archery" score for each shot depends on the bowling score and on the bowler level.

The level set by default to all bowlers is Medium but it can be selected for each bowler before starting the game in the Bowler Options or though the console, via the Bowler menu item. The available skill levels are Easy, Medium, Hard, Expert. If the player scores 40 at Medium level, he will automatically be promoted to Hard (and from Hard, to Expert).

At the end of the game, the game targets can be printed and given to bowlers.
