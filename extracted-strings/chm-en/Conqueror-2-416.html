4. MMS Monitor Setup

Setup > Technical Setup > Multi Media System

The technical data necessary for the functioning of MMS is set in this tab: to set a new Multi Media System, press New , so that the scroll menu contains the new option i.e. "MMS 1", "MMS 2".

For every MMS set, insert the Serial Number , and set both monitor specifications and define the coordinates for the image.

With RDB hardware, the MAC Address has to be entered.

When the MMS needs to be restarted, press Reboot .

To eliminate a set MMS, select it in the scroll down menu and press Delete .

With RDB hardware, the Message Displayed when Lane Available option is available, where entering the blinking message to be displayed on the right-hand side of the screen of the MMS screen, when a lane becomes available. By default, the Go to Front Desk message is entered, but it can be overwritten. If no message is specified, the right-hand column remains empty and only the player name blinks.
