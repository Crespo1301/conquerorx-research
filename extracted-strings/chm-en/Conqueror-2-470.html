6. Quick Buttons

Select the Quick Buttons to be utilized from the External Frame of the Main Menu for the terminal being utilized.

Up to 6 programmable buttons can be chosen, to be displayed on the right-hand side of the screen, personalizing the system for either user or terminal, in making frequently used modules easily accessible.

The Clear Display quick button appears only if a display is connected in the Devices tab.

Urgent Tasks

There are different types of notifications to which the operator has to react as soon as possible. Tasks requiring immediate attention are displayed in a window called Tasks Requiring Immediate Attention , which opens when clicking on the new Urgent Tasks Quick Button .

Select the urgent tasks to be managed from the current terminal among Picture Validation , Virtual Waiter , Lane Orders .
