3. League Setup

Press the Setup button in the window containing the league details, to access the League Setup screen, where information regarding that particular league can be modified.

League Type

Choose the league type such as Women, Seniors, Juniors, etc. from the drop down menu.

Week Day

Indicate the day of the week on which the league is being played.

Games per Session

Define the number of games to be played each week.

Week Number

Indicate the number of weeks since the beginning of the league.

Structured Number of Players

Enter the total number of players expected.

Enrolled Number of Players

Specify the number of players actually signed up to play in the league in the week selected.
