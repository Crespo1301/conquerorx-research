5.7 Importing Reservations

Back Office > Reservations > Import Reservations

Through this window it is possible to import a reservation previously defined in an Excel file.

The Excel file contains the reservation data: date, time, game type, bowling quantity, contact name, contact phone number, FB ID, and for each bowler it is necessary to specify: name, lane, team name, position on the lane, handicap, gender, bumper and bowler attributes.

To proceed, first choose the file to be imported by clicking on Import Excel file , then specify the lane where to start looking for the bookable lanes (Start Auto-allocation from Lane ) and start the import procedure by pressing Import.

The result of the import procedure is displayed for each file and it is possible to open the Booking System with the imported reservation automatically selected.
