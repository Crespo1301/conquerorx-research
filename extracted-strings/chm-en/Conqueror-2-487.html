9.3 High Scores - Setup Tab

Use this setup to activate a High Score and decide on which Hyper games the settings must be applied, define a subtitle and set an entry score for each ranking. It is also possible to change the start date of the All-Time High Scores (e.g. beginning of the previous year); and in the case of custom High Scores, centers can define a start and end date within which the ranking would be running.

To define a custom High Score, users must enter a title and define a start and end date which cannot overlap the date range of another custom High Score. The name of the custom High Score is displayed during celebration, and both title and subtitle are shown on MMS standings and printing. To change the name of "dummy" players, used to populate standings with less than ten real sessions, use the "Default Players" button.
