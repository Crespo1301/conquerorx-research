3.1 Timeouts in Seconds

Environment Choice

When the number of bowlers is entered, categories are opened and then the environment choice. If this timeout expires and the environment has not been chosen, the bowler name insertion is opened. The environment automatically set is the Lane Option default. If the credit is not enough for it, the environment set is the first of the category.

The default is 60 seconds.

Single Player Sign-in

A global timeout equal to 30 seconds per player is available for the player sign-in. It the timeout expires and the screen has not been touched, the Ready to Play screen is displayed.

YouToons Pictures

If YouToons has been chosen, the app allowing to take the bowler picture is open. As soon as the first bowler has snap their picture, they can throw the first ball, and the second bowler can take their picture. This timeout is related only to the first throw.

Bowler Number Choice

Choose the number of seconds available for entering the bower number.

Ready to Play Screen

The Ready to Play screen is opened. The game begins when the Play button is pressed or when the first ball is thrown or when this timeout has expired.

End of Game Choices

At the end of game, bowlers can choose between inserting coins in order to continue the current game or to start a new one. When the timeout has expired the lane is open starting a new game.

Warning Message

Number of seconds after which the Warning Message is automatically closed.

Explanatory Screen

Number of seconds after which the Explanatory Screen is automatically closed.

Bowler Throws

Timeout for every single throw.

SuperTouch App Closure

If the SuperTouch is not open on the main menu but on another app at lane closure (e.g. on Lane Chatter), the SuperTouch will be automatically after this timeout.

Recap Closure

In the case the Automatic Recap is enabled in the Lane Options, it is displayed and then closed after this timeout has expired.

Standing Closure

If a player is present in a standing, it is displayed and then closed after this number of seconds.
