3.1 Assigning Special Games to Lanes

Setup > Bowling Setup > Lane Options

Lane Options can also be accessed through the Lane Status module.

Once the Special Game session has been set as desired and saved, it can be applied to lanes.

In the Basic tab in the Lane Options module, it is possible to set the Special Games to be played by clicking on the Special Games option. Having done so, a window appears where the desired session of one or more Special Games, can be assigned to (or removed from) lanes.

It is also possible to set the Environment to be displayed on the lane monitors during the Special Games between Prehistorica, Oceano, Bubble Gum, Fairy Tales, Vintage, Disco, etc.

BES SPECIAL GAMES > Management of Special Game Sessions > Assigning Special Games to Lanes
