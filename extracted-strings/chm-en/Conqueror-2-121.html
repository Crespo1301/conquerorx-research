18. Lights - Lane Effects

Setup > Bowling Setup > Lights - Lane Effects

A set of default effects is provided, but new sets with custom effects can be added.

Legacy AMF scoring system not supported

States and Events Default Effects

States supported are listed in the first tab, with a default light effect already associated. Events are listed in the second tab, with a default light effect already associated. The latter is supported only in BES X centers.

Managing New Light Effect Combinations

Select, from the dropdown menu, the combination to modify, copy or delete; or press + to create a new one. Each effect (States/Events) of the combination can be customized using the Edit Effect button. The Test Effect button sends the selected effect to the lane for a few seconds.

Customizing a Light Effect

To edit a state or event, double click or press Edit Effect .

States: select Off to disable any effect; Deck and Bumper Lights have two different to be customized separately. However, Deck and Bumpers cannot run a different Light Effect . The features of the light effects are the same as those discussed in the previous paragraph (Lights - Global Moods). Flag Join Global Mode to apply the Global Mood to the selected state. Lane on and Practice have an additional feature, called Ball tracking. To activate it, select an option from the dropdown menu and choose between "Cursor" and "Comet". The former is a light that follows the ball, and the latter creates a "glow effect" on the bumpers.

Events: this tab indicates events occurring during a game. To open the Event setup window double click on an event or press Edit Effect . Deck and Bumpers lights work as previously described. Select No Effect to keep the "Lane on" effect even when events occur. Modify the duration of an effect using the "Duration" box. As an example, strikes can last longer than faults.

Overriding Lane Effect or Global Mood

Use this function to temporarily override lane effects and/or global moods on a given lane set. Use it on: a single lane / group of lanes to set a color or an effect for testing or maintenance purposes; celebrating an event, such as birthday parties; or on the entire center / selected areas of the center to override Global Mood sequences defined in the Bowling mode for a certain amount of time. After the time is elapsed, lanes return automatically to their associated light effect.

Associating a Light Combination to a Bowling Mode

A Lane Lighting Combination can be chosen for each Bowing Mode. The lights combination can be different for different lane sets. The Lane Lighting box consists of two sections; click on Lane Effects and/or Global Mood to open the drop-down menu from which the light combination can be selected.

Light Effect Combination Lane Option

Use the Lane Options module (Advanced tab) to define a new Light Setting , doing so allows overriding the Bowling Mode settings. To change light settings, select the Custom option and choose a combination from the drop-down list.

Lane Lighting Server Setup

Setup > Technical Setup > Lane Lighting Server Setup

Enable the Deck Lighting Server by entering the Serial Number in the dedicated field and clicking Enabled . The red/green light indicate the server status.

After a version upgrade, the programs must be uploaded. In this case, the plugin automatically opens, and the program upload can be directly managed.

Open Lane Console Light

It is possible to set up and personalized the console lights. The user can select any set of lights currently available by default. Please beware: there are no available effects for console lights.

Enable Console Event Effects

In some occasions, such as "Sign In", console lights can vary.
