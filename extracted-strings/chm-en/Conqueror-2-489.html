10. HyperBowling Tests

SETUP > TECHNICAL SETUP > HYPERBOWLING TESTS

Perform the test to ensure the smooth functioning of Hyper games and provide a seamless gaming experience. Run the tests to promptly identify errors and keep Hyper bumpers in the best possible operating conditions.

Flag Access the Hyper Bowling tests module privilege to access the HyperBowling tests module.

HyperBowling tests module consists of two main tabs: Overview and Details. The Overview tab displays the status of all the lanes in the center; the frame turns yellow when selecting one or multiple lanes. All test buttons are located at the bottom of the window and are identical in both tabs. The Details tab simply provides more details. Click the left or right arrow to move from one lane to another.
