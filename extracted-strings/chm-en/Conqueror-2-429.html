1.2 Web Reservation Global Settings

Allow Payment without Activation

With this option enabled the web customers will not receive the confirmation e-mail and will be able to pay directly after entering their data in the form. After payment they will receive 2 e-mails confirming their activation and their payment.

CV2 Code Necessary

Enable this option if the web customer has to enter the CV2 code when paying by credit card.

Reservation Time Unit (Minutes)

The unit of measurement for web reservations is set here (e.g. 15 or 30 minutes). This is also the minimum amount of time that can be booked.

The number of minutes has to be a multiple of the Grid Time Unit of the Reservation Sheet set in Center Setup > Reservations.

Book before Playing (Hours)

Specify how much time (hours) in advance the customer must book.

Display Price Keys Available before/after Selected Time (Minutes)

The main price key associated to the scenario will be displayed in the Experience window of the website in boldface type, but it is also possible to display alternative price keys to the customer.

With the 2 options Display Price Keys Available before Selected Time and Display Price Keys Available after Selected Time it is possible to set the time frame within which alternative price keys have to be suggested.

Maximum Playing Duration after Last Bookable Time

Specify the time before which a web reservation has to finish after the last bookable time in order to avoid accepting web booking that are destined to run beyond the bowling center closure time.

E.g. Bookable Times 1.00 p.m./11.30 p.m. and Web Last Playing Duration off-set 1h30: a web customer can book from 11.00 p.m. until 1.00 a.m. because 1.00 a.m. is between 11.30 p.m. and 1.00 a.m. (1.00 a.m. = 11.30 p.m. + 1h30)

Default Password for Web Users

Members with the Web User option enabled can login to the Center Website using their e-mail address and the default password set here.

After logging in with this password, the member can choose a personal one.

Reservation Conditions

Enter the conditions customers have to respect regarding their reservation.

The Reservation Conditions entered here will be displayed below customer requirements and will be highlighted in boldface type in the reservation confirmation window.

Menu Choice Message

Enter here a customized message to be displayed on the website in case of sell open choice menu.

Disabled Scenario Message

Specify the message explaining to the web customer why web reservations are not accepted at that specific day/time.

The message is displayed in the Extended Availability page when the web customer passes with the mouse over a not-bookable cell. E.g. "Sorry but on new Year's Eve we don't accept web reservations, please call 800-222222 to book."

Discount Display Setup

Discounts can be highlighted on the website with a colored label, in order to boost the reservations during the empty hours. To use this feature, press Discount Labels and define the 3 discount ranges that will correspond to 3 different colors.

The discount is also highlighted in the confirmation e-mail and in the Reservation Details window in order to make the operator and the customer aware of the applied discount.

Lane Groups

This feature allows to avoid web reservations on different lane groups, for example, on two lane groups for split houses: the first group on the ground floor, the second group on the first floor. In this way customer groups will not be assigned on different lane groups, e.g. they will not find themselves on different floors.

Give the first Lane Group an appropriate Name (e.g. "1st floor") then enter the group starting lane (From Lane ) and ending lane (To Lane ).

Lane groups are set as Bookable Via Web by default. Disable the option for the lane groups dedicated to walk-in customers.

Specify also if in the Bowling Center:

  • it is possible to accept reservations on different groups when there is no availability in the same group.
  • reservations are only on lanes pertaining to the same group.

Fee Setup

Fees applied to reservations can be:

  • a Fixed Amount : in this case, the amount entered here will be charged for each web reservation.
  • a Percentage : in this case, the fee will vary with the reservation total. Enter here the percentage to charge.
  • a Fixed Amount per Game : in this case, the amount entered here will be charged for each game included in the reservation
  • a Fixed Amount per Player : in this case, the amount entered here will be multiply by the number of bowlers included in the reservation

For the last 3 options it is possible to set the minimum fee that has to be charged and the maximum fee that can be applied. E.g. Enter 1 as the minimum fee in order to charge 1$ even if the fee calculated is lower than 1$. Enter 10$ as the maximum fee in order to charge 10$ even if the fee calculated is higher than 10$.

These settings only affect web reservations. In order to manage fees for local reservations, similar settings have to be specified in Center Setup.

To void or remove the predefined booking fee the relevant privilege is required.
