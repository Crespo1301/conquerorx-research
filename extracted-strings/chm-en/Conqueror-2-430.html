1.3 Bookable Days and Times

It is possible to prevent web reservations on a particular day of the week or on a specific date, to define a specific opening time and last bookable time for particular calendar days. Moreover it is possible to specify the time before which a web reservation has to finish after the last bookable time in order to avoid accepting web booking that are destined to run beyond the bowling center closure time.

Define the time range within which booking is possible for each day of the week and enter a message to be displayed to the web customer when passing the mouse pointer over an unavailable slot. E.g. "Sorry but it is not possible to book lanes from the web for Saturdays, please join us directly at the Center."

To create a particular rule for a specific calendar day (e.g. September the 8th) press + , choose the date and:

  • disable web reservations for that specific day and enter a customized message for the web customer

or

  • customize the time range in which web reservations can be made.

E.g. Bookable Times 1.00 p.m./11.30 p.m. and Maximum Reservation Duration after the Last Bookable Time off-set 1h30: a web customer can make a reservation that starts at 11.00 p.m. and finishes before 1.00 a.m. (1.00 a.m. = 11.30 p.m. + 1h30)

Rules defined for specific calendar days overwrite the default rule defined for that day of the week; e.g. if Halloween is a Friday, the October 31st booking time is applied, not the standard Friday one.

These times have to be compatible with the Bowling Center Opening Hours set in Center Setup > Reservations.
