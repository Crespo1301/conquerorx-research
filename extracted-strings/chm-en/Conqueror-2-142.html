31. Lane Highs

Front Desk > Lane Control > Lane Highs
BES, Bowland and Bowland-X Only

Through this screen, the highest scores (or tournament winners) can be prepared to be sent to closed lanes, whether they be for leagues, tournaments or general high scores achieved in the Center.

For each pair of lanes, various pre-set messages can be created and saved, each with a different layout.

To transfer these scores to the lane monitors, select the Historical Highs option in the Impact Images module and then press Enable .

New

Select the desired pair of lanes in the list on the upper left-hand side of the screen.

Press New to create a score page and choose how the scores are to be viewed by selecting how many headings are to be displayed from the Layout list.

When the 3 Columns option is selected, icons for first, second and third place can be included with the scores by checking the Show Bitmaps option. Whereas for the other selections, the headings are displayed in yellow on the monitors.

Then complete the various fields with the data that is to be displayed on the lanes.

The list at the base of the screen contains messages regarding the selected pair.

Delete

Press Delete to delete the score page selected.

Preview

Preview displays the actual layout of the selected page on the lane monitors.

Copy to

Copy to allows copying the pages directed to specific lanes, to other pairs. The new page will have the same name as the source, but it can be modified while copying.

Clear

Clear deletes the text of the current message.

Save

Save saves the current settings (enabled only if changes have been made).
