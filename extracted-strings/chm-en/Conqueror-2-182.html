4.2 Advanced

No Longer a Member

Check this option if a member wishes to cancel their membership, but the Center still requires the member details.

The ex-member's details remain in the database so that if they later wish to re-activate their membership, it can be performed easily.

Privacy

In the Privacy section, specify if the Frequent Bowler allows the center to contact them by post/mail, e-mail, text message and/or by telephone.

When the first option is enabled, the other ones are set automatically, but the operator can still change them one by one.

Data Available for Others

Selecting this option reveals that the information regarding this member can be shared with external parties for purposes such as publicity, according to the laws of privacy.

Can Be Contacted Directly

The operator has the ability to create a new Frequent Bowler. After doing so, the operator clicks on the "Links" tab so that he/she can add a new member. This new member does not own an account but, on the contrary, his name is linked to the main frequent bowler. Once created, the operator can flag the option "Can be contacted directly" which means that regardless of the fact that the bowler does not own his/her own profile, her/his account appears in the list of all the Frequent Bowlers. Unflag this option to hide any linked bowlers from the frequent bowler list.

Statistics

This caption reveals information regarding reservations, no shows, cancellations and automatic cancellations as of a specific date.

Press Reset Counters to reset these statistics to zero and to the current time and date.

Registration Date

Select the date that the member was signed up here.

Expiry Date

Enter the expiry date of the membership.

One Year Extension

Press One Year Extension to extend the membership for a year.

This option is available only if the membership expiration date was set.

Discover Source

Select the place where the member first discovered this Bowling Center (useful for advertising purposes).

The Discover Sources available in this scroll down menu have been previously set in Center Setup.

VAT Number

Enter the VAT Number that has to be printed on the member's invoices.

National Code

Enter the member's taxation number here.

Free Entry Code

The free entry code refers to the sanction ID code for federation bowlers.

Tax-exempt ID

Enter the member Tax-exempt ID .

If a tab is linked to an FB with a Tax-exempt ID, when the FB pays the tab, the system automatically uses the Tax-exempt ID to calculate the tab payment total with tax exemption.

Company Name

This option allows adding the name of the company for which the player works.

Notes

It is possible to enter any other relevant information regarding the member, in the Notes section.
