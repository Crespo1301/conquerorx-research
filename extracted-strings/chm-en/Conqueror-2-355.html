6. User Log on and Log off

6.1 Log on

Working with Security activated requires that each Conqueror user identify themselves whenever entering onto the Conqueror system, whether starting their Shift or replacing a colleague.

This is done either through fingerprint recognition, swiping the membership card or inserting the User Name and Password in the Log on panel (the default which is displayed is the previous user).

After 6 consecutive failed attempts to log on after inserting a wrong password, the operator is disabled. On the 7th failed log on attempt a message appears informing the operator that they are blocked out and cannot attempt another log on for 30 minutes. However the operator can access Conqueror using the fingerprint sensor or by swiping their card, if present.

Setting the Diversified Users Settings option in the Terminal Setup allows each operator to maintain their personal Conqueror preferences that are activated as soon as the operator logs on. It allows either distinct options for each user or all local options shared by all users.

Select User Profile

The operators can choose between the profiles at their disposal (the Default Profile is that defined in Staff Setup).

Change Password

From the Log on screen the operator has the ability to change the operational password by clicking on Change Password and following the on screen instructions.

Center to Connect to

This option is only visible if the Remote Mode license has been purchased.

It is possible to select which Center the terminal is to be connected to for remote use of Conqueror.
