19.1 Managing Global Moods

The Global Moods window allows you to add, modify or choose a sequence of effects, which can include Lane Lights (Deck only/Deck + Bumpers lights) and Capping lights.

There are four buttons and one drop-down menu at the top of the window.

Use it to select an existing Global Mood or in alternative:

      • Add a new Global Mood by clicking the + sign.
      • Duplicate the current Global Mood by clicking the Duplicate button.
      • Edit the current Global Mood by clicking the Edit button to rename it.
      • Delete the current Global Mood by clicking the delete button.
