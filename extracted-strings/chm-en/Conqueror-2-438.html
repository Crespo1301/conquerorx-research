2. Bowling Mode Setup

First it is necessary to create at least one Bowling Mode and specify Lane Option Set to be used.

and the Coin Options active in that bowling mode (combo box "Default lane options" and "Coin options").

Note: it is important that the two combo box are set to a value and are not leaved empty.

When the bowling mode changes, the related Coin Options are sent to all the lanes.

Coin Mode Lane Options

This setup (accessible from the menu "Coin Mode Options") defines the Lane Options to use when the lanes are open in Coin mode. In particular defines witch environments are selectable from SuperTouch when a new game starts.

The Lane Options not used in coin mode are shown disabled, with their default value (e.g. the Keyboard is always checked).

Note: this set is different from the set under the `Lane Options' menu, that defines the Lane Options for the normal bowling mode (i.e. lanes opened from Conqueror terminals).
