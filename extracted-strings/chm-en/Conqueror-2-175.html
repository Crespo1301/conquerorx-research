9.2 QuickBooks Desktop Account Settings

The account export function is used to join the income of different price keys or departments all into a single account.

A QuickBooks Desktop account is composed of an alphanumerical identification code, a description and a type (e.g. NAB 234 Non-Alcoholic Beverages).

The QuickBooks Desktop import function works if the file exported from Conqueror Pro contains accounts that are not present in QuickBooks Desktop or that are defined in the same way in both Conqueror Pro and QuickBooks Desktop.

To make this operation easier it is possible to synchronize the accounts defined in Conqueror Pro with the ones in QuickBooks Desktop by following this recommended procedure:

  • Under Center Setup > Shifts press Setup to open a dialog window with tabs.
  • Set the QuickBooks Desktop Account Code (alphanumerical identification code) for each price key, department, tax, modifier, payment mode, etc. and then Save .
  • All the defined accounts with a default description and a type (both can be modified) will be displayed in the last tab.
  • As all the accounts have to match with the ones in QuickBooks Desktop, it is advisable to proceed with the automatic synchronization rather that the manual one.
  • Access QuickBooks Desktop and export the list of accounts through the following path: File > Utilities > Export > List to .IIF File. In the small window that opens select Charts of Accounts, press OK and then select a directory to save the .IIF file (that contains the accounts to synchronize with Conqueror Pro).
  • In the QuickBooks Desktop Account Setup window of Conqueror Pro, press Synchronize , select the file exported from QuickBooks Desktop and confirm.

At this point Conqueror pro will check if all the accounts in the Account List tab are defined in the same way in both Conqueror Pro and QuickBooks Desktop.

If any differences are found, they will be highlighted in a specific window that contains a button for "correcting" the accounts in Conqueror Pro. If a correction is carried out, it is necessary to save before exiting the window in order to make the changes effective.

The synchronization function is not used to import accounts from QuickBooks Desktop (probably in QuickBooks Desktop there are many accounts that are not necessary to Conqueror) but it is used for matching accounts defined in Conqueror Pro with the definition present in QuickBooks Desktop.
  • Select the Account Export function in the setup window. The export of the file to QuickBooks Desktop is automatically carried out (if enabled) upon shift closure or on demand from the Shift Reports.

Exporting Payment Modes

When closing a shift, together with the other data, the Payment Methods can be exported to QuickBooks Desktop, differentiating every credit card type.

Choose a Payment Mode Export option, from: Never , Always (payments are exported, but without differentiating the credit card type used to pay), Always with Credit Card Details (the different credit cards used are exported, separated by the Card Scheme code returned by the credit card providers; in this case it is necessary to configure the Credit Cards tab).

In order to `export by account', enable the Export by Account Numbers option and set the QuickBooks Desktop Account Code for each credit card type.
