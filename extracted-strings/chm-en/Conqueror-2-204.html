12.3 Player Club Cash

Members can use the points received through the Point Collection scheme to pay in the Payment window through the Player Club Cash feature.

In the lower part of the Point Collection tab it is possible to enable Player Club Cash Payments and to set the conversion rate between points and cash. E.g. if in the Center 4 points are needed to pay 1 Dollar/Euro (or 1 unit of the Center currency), set 4 in the Currency/Point Conversion field. In this case, to pay 10 Dollars/Euros etc. the member must have at least 40 points on their card.

Set the Player Club Cash payment mode in the Denomination Setup to display it in the Payment window and to use it for members.

In the shift reports an optional section displays information on payments made using the players' points.

Note that for Player Club Cash payments it will not be possible to combine different payment types.

The default values have already been set in this tab, but they can be customized for each member category: select a member category in the Categories tab, press Modify and deselect the Default Currency/Point Conversion in the modification window that opens and then enter a new value in the Currency/Point Conversion field.
