12.1 Accounting Software Interfaces

Micros

Centers using Micros interface have to enable it in this window. For more details about the Micros parameters to be entered, please refer to the documentation provided at center installation.

WinTic

The WinTic Interface requires a specific Conqueror Pro license.

Conqueror Pro can work with this accounting software for the management of cash operations.

To use WinTic software it is necessary to:

      1. Enable the Export to WinTic , define which computer is the server for the WinTic application, enter the Port number and specify Connection Timeout and Response Timeout (both in milliseconds).
      2. Associate WinTic codes to the price keys to be exported.
      3. Configure the WinTic software accordingly (carried out by a qualified technician).
Cancelling a WinTic price key is considered a Suspect Action, and is therefore reported in the Shift Reports.

It is recommended to avoid rounding price keys in order to prevent total discrepancies between the Conqueror Pro and WinTic; in the Currency Setup, set 2 Decimal Digit and the Rounding Unit to 0.01.

Fixed discounts on single price keys are managed for both the Italian and the Romanian markets. For a technical limit of WinTic on rounding and subdivisions of the account part of SIAE, in the Italian market it is necessary to avoid using percentage discount on the single price keys. For a technical limit of WinTic on rounding, it is necessary to avoid using discounts on the transaction total (for both markets).
