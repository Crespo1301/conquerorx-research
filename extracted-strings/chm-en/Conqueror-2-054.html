12. POS Setup

Setup > Price Setup > POS Setup

Tip Management

Enables all the features regarding tips, in particular the print of the line of the credit card receipt referred to tips.

Use Tabs Screen as POS Main Window

Enable this option to display the Tabs management screen as main screen of the POS Module.

Display Price Keys Needing Authorization

This option allows the manager to control the sale of particular items, e.g. some discounted price keys can be reserved only by managers, while others can be used also by operators managing reservations.

First set the price keys requiring this particular control as Authorization Required. Then, enable the Sell Authorization Required privilege only to operators who may sell these special price keys.

There is a second level of authorization, setting price keys as Authorization Required - Type 2 and the Sell Authorization Required - Type 2 Price Key user privilege.

Kitchen Printer Profiles

Configure printer profiles of 3 printers and the time ranges each printer will be used in: press New , specify a profile name, select the first printer, set the time range this printer will be used in (Start Time , End Time ) and then proceed in the same way for the second and the third printer.

The printers available in the scroll down menu are the printers installed on the Conqueror Server computer.

Then printer profile has to be associated to the relevant F&B sub-departments.

Click on the Font icon in order to customize the layout of kitchen receipts. To remove the customization and go back to the default, disable the Custom Font option.

Tab Assigned to the Last Operator

With this option enabled, tabs are assigned to the last operator having worked on it.

Organization Number

Swedish Market Only

Conqueror Pro can work with CleanCash, a fiscal control unit compliant with the regulations of the Swedish National Tax Board.

To use this interface it is necessary to enter the Organization Number provided by CleanCash, and the receipt printer must be configured and properly connected.
