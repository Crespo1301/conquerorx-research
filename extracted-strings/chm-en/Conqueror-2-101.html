13. Special Functions - BES & Bowland

Lane Status > Special Functions

Special Functions are a series of functions that can be applied to a lane or to a group of lanes.

To apply any of the Special Functions, first select the lane and then press Special Functions to apply the desired function as follows.

Split/Merge

Divide a pair of lanes into two single lanes by selecting the pair and pressing the Split button.

Join a single lane with its sister lane (if compatible) by selecting it and clicking on Merge .

These functions are unavailable if lanes are opened in Time mode with the Charge Double Time option checked in Center Setup.

Last

Press Last to display the last photo of the pins taken by the camera on the lanes selected.

TV

Press here to access the settings of the monitor/TV connected to one or more pairs of lanes.

In the case of the Accuvision monitor, each monitor can be setup separately: both monitors on the pair of lanes plus the central one, when present. The data source will be different: lane-off picture/advertising, integrated single channel TV, multi-channel TV, AV1, AV2, component input and HDMI. If the multi-channel TV is selected, it is possible to choose a particular channel on tuner 1 or 2.

If the selection includes lanes with different settings, a question mark will be displayed on the monitor image.

Reopen

Reopens the lane with the same settings (options and players) of the last bowling session (the games played will be put together with those played previously).

Example: the game has finished, the lane is closed but the players change their minds and wish to continue playing.

Skip Boot Error

When the Lane Control Box has a boot error, it is possible to force its functioning by using this button (that is, open the lanes), thus ignoring the error.

When errors occur regarding TV PIP for example, that is not vital to the development of the game and therefore the customer wouldn't notice the malfunction, this button comes in handy. On the other hand, when an error occurs regarding the pinsetter, this option allows the lane to be opened, but the pinsetter commands will have to be entered manually on the keyboard, in the same manner as scores are inserted.

This button is useful during tournaments when continuous play is essential, even if it requires that tasks be performed manually.

Transfer Bowlers

BES, Bowland and Bowland-X Only

To transfer players from one lane to another available lane (whether open or closed), click on the Transfer Bowlers button, choose the destination lane and press OK , then select the player to be transferred and the amount of time (Time to Transfer ) if the session was opened in Time mode. If the lane was opened in Game mode, the remaining frames to be played are entered automatically.

Pogo Pin

Bowland and Bowland-X Only

Press here to activate the Pogo Pin game on the selected lanes.

Strike Challenge

BES, Bowland and Bowland-X Only

Press here to access the Strike Challenge setup and management.

Lucky Train

BES Only

Press here to activate the Lucky Train global game on the selected lanes.

Swap

Swap players in a pair of lanes, from one lane to another.

Keyboard

Opens a keyboard simulating that on the lanes, allowing the operator (instead of the players) to send commands to the lanes.

Volume

The Volume option controls the general volume on the lanes, while the volume of Special Games , TV , animation/advertising in Lane Off and for bowling sessions and animation in Lane On can be controlled separately. The Mute button turns the sound off completely which may be utilized when a loud-speaker message is to be transmitted, for example.

This panel is only accessible if the Sound option is checked in Center Setup.

The Lane Off and Games options are only available for Bowland Centers.

Monitor Image

Displays the image of the monitor of the selected lane.

Restore Last Game

BES Only

If the player goes to the following game by pressing the keyboard by mistake while the current game is not finished yet, they can ask the operator to restore the interrupted game.

This function is available only to the operators with the Restore Last Game through Special Functions privilege.

Lane Lights

This function gives you the possibility to temporarily override light effects on a given lane set. You can use this function:

On Single lane / Group of lanes to set a color or an effect for testing or maintenance purposes; and celebrate an event, such as birthday parties.

Entire center / Selected areas of the center to override Global Mood sequences for a certain amount of time.

To use these functions flag the following privileges: Access to Global Moods Setup and Access to Capping Light Setup .

Lane lights consists of two tabs: Lane Effect and Global Mood. Select Lane Effect to modify Deck light and/or Bumper lights. You can switch the lights off, select a set color or in alterative choose an effect from the Light effect (deck + bumpers) list. Choose any effect from the list, you can modify it or run it as it is. To modify an effect use the options below:

      • From /To Color : Define the color range that you want to rotate (From) and the color range you want to rotate (To). Double click on the color to open the color palette.
      • Speed : Modify Speed of the effect, open the drop-down menu and select your speed.
      • Direction: Modify the direction of the effect. Please note: this option may be available only for selected effects (e.g. Wave).

To run the effect click Play , click Stop to interrupt the effect and let the one set in the Bowling Mode run back again.

The Global Mood tab allows you to change the Global Mood of the center on a given lane set just for a limited amount of time. Use the drop-down menu to choose a Global mood previously set up; use the Lanes field on the right of the window to select on which lane set the effect must run on and then set the duration.

To run the effect click Play , click Stop to interrupt the effect and let the one set in the Bowling Mode run back again.
