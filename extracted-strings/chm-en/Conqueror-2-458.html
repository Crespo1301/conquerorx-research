6.4 In AS 80/90 Centers

Free Frames

Free Frames are extra free frames that can be played on the lane in case of a prepaid game.

If a player cancels a frame in order to play it again, it would not be possible to finish the game because the lanes would close after the 9th frame. To allow the player to finish the game it is possible to set a few Free Frames .

Set how many Free Frames are to be accepted on the lane.

Time Pause between Pinsetters on

This option allows the user to program an interval of a few seconds between the activation of a pinsetter and another.

The selection of this setting is recommended because the activation of all the pinsetters at the same time requires a considerable amount of electricity.

Lanes to Be Scanned

Enter the number of lanes to be scanned by the system every second (to update game data, automatic closure, etc.).

The values allowed are between 1 and the total number of lanes of the Bowling Center.

F-out Relay Pulse Duration (msec.)

Set the duration of the impulse of the F-out device relay (in milliseconds).

Billiard Light Controller Port

In the presence of a Billiard Light Controller, select its COM port on the Server from the scroll down menu.

Favero Pool Control System

If the Center Time Games are controlled by a Favero pool control, select its COM port on the Server from the scroll down menu.
