4.2 Creating Departments

Press New Main Dept to create a new main department and press New Dept to insert a new sub-department (it will be positioned straight under the department selected).

Give the department a Name and enter the following settings:

Unit of Measurement

Enter the Unit of Measurement label: `Pairs' for shoes, number of `Hours' for Time Games, etc.

Display Order

It is possible to choose which sub-departments are to be the first ones displayed in the structure and in the POS by assigning them a progressive number.

This is not compulsory: if no number is assigned, the display order will replicate the insertion order and the first sub-departments to be listed remain those first inserted.

Department Type

For new main departments specify the Department Type between Food and Beverage, Income, Pro Shop, Miscellaneous.

Price keys included in a Food and Beverage department will be displayed in the Sales window when entering through POS > Income > Food and Beverage menu; price keys included in an Income department will be displayed in the Sales window when entering through POS > Income > Other Income menu, etc.

Default Category/Create New Main Category

For each department and sub-department it is possible to set a Default Category : price keys created in the department will be automatically associated to the category selected in this scroll down menu.

It is also possible to create a new main category for the price keys that will be added in the department being created.

Color

Choose a Color for the department: the price keys pertaining to it will be displayed in the Sales window in this color. The default color is the color of the parent department.

Printer

For the sub-departments pertaining to the F&B main department, set a specific printer or printer profile. For example, the kitchen item department has to be associated to the kitchen printer so that kitchen orders will be printed on the printer set here.

The price key sent to the kitchen printer are those set as Kitchen Printable in the Price Key Setup.

Enable the Printer Profile for all Cash Drawers option in order to link a single printer profile for all counters. Disable it to be able to specify a different Printer Profile for each Cash Drawer . To do this, click in the table and choose for every cash drawer a specific profile, between those previously set in the Kitchen Printer Profiles.
