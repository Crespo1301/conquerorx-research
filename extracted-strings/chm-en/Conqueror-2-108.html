15.4 Bowling and Lane Services

BES Only

The Bowling Services and Lane Services menus allow bowlers to select various functions from the lane keyboard.

Bowling Services

The first menu, Bowling Services , proposes:

  • Service Call : allows bowlers to call the front desk operator when necessary. When this occurs, the Lane Status module displays the SOS flashing light on the relevant lane.
  • Recap Sheet : displays a summary of the games for each player on the lane monitor.
  • Statistics : proposes statistics on the highest score, best score, the number of Strikes, Spares, Gutters, etc. for each of the players.
  • Technician Call : allows the players to call for technical assistance through the Trouble Call System. When the call is registered, the players can see the progression of the work in progress through the animation on the monitors (the telephone ringing, QuPee working on the problem, etc.).
  • Pinspotter Functions bowlers can either reset all bowling pins to their correct position or clear fallen pins.

Disable Automatic Recap

Enable this option to disable the automatic end-of-series recap sheet displayed on the lane monitors.

Lane On Advertising

Enable this option to let advertising images appear on the scoring monitors at certain intervals during play

Cleaning mode after lane closure

Enable this option to let the Conqueror (from version 11) make the lanes automatically go into Cleaning Mode at the conclusion of a bowling session

Extend Bowling Session

Enable this option to let bowlers Extend the bowling session directly from the lane. Automatically prompt customers at the end of the game to extend their prepaid session without leaving the lane.

Intercom

Option allows players calling the front desk from the lanes.

Lane Chatter

SuperTouch Only

This option enables the Lane Chatter on the lane console.

Bowler Photo

This option allows the players to take photos of themselves.

Selfie Grid Photo

This option allows setting photos as grid background.

GameConnect

SuperTouch Only

This option enables Facebook GameConnect on the lane consoles.

Virtual Waiter

BES X Only

This option enables the Virtual Waiter on SuperTouch devices. For further information about how the Virtual Waiter works, check the 25. Virtual Waiter and Video Intercom Setup paragraph.

Video Intercom

BES X Only

This option enables the Video Intercom on SuperTouch devices. For further information, check the 25. Virtual Waiter and Video Intercom Setup paragraph.

Takeaway Picture Message

BES X Only

This option is available for Mad Games only and only if the bowler has selected the Mad Games by using the Choose your Experience button on the SuperTouch. Enable this option to add information in the Explanatory Screen on how bowler can ask the Front Desk to print their Monster or Character.

SuperTouch Slideshow

· Automatic Statistic Slideshow

This option allows operator to enable the Game Progress, results in the grid, Frame Progression score and Frame Progression Pin screen on SuperTouch devices. The types of screen displayed depend on the game the bowler has selected.

· Scoring Grid

    • A) Flat, updated in real time: This is a screenshot of what the SuperTouch currently displays
    • B) SuperTouch Slideshow: this option shows all the frames and players on one screen without having to swipe up or down. Like the grid on overhead monitors, the new one displays the list of the bowlers currently playing on the lane, whilst the type of score displayed in the "Total" column depends on the option previously set in the Lane Options module.
