3. BES X GameConnect

Setup > Web Setup > GameConnect
BES X Only

Enter these settings in order to use the GameConnect feature.

Fan Page Address

Paste here the link of the Bowling Center Facebook page.

Website Link

Paste here the link to the Bowling Center website.

When a GameConnect automatic post will be clicked, the website linked here will be open.

Link to Center Logo

Paste here the link to the Bowling Center logo, which will be displayed in the login post.

The default picture is the BES X logo.

Login Post Message

Enter the message to be displayed as default in the login post; i.e. when a bowler performs the login trough the SuperTouch.

The default message is "I just got the ball rolling".

Post Caption

Enter a customized caption, e.g. at Sun Valley Lanes.

The default caption is "with BES X".

Post Description

Enter a customized description, e.g. the Bowling Center website address.

The default description is "www.qubicaamf.com".
