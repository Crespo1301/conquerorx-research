14. Special Functions - Universal

Lane Status > Special Functions

Special Functions are a series of functions that can be applied to a lane or to a group of lanes.

To apply any of the Special Functions, select the lane and press Special Functions to apply the desired function as described below.

Advertising

Not available with Frameworx

Allows access to the Advertising module.

Clear NV

Frameworx Only

This function sends a reboot command to the lane scorer deleting all the game data stored on the CPU.

Hold Lane

Not available with Frameworx

This option, enabled only in case of Time Mode , stops time on the lanes.

Lanes on hold are highlighted in the Lane Status.

Intercom

Frameworx Only

Allows the front desk operator to start and to close an Intercom call with an open lane.

Keyboard

Not available with Frameworx

Opens a keyboard simulating that on the lanes, allowing the operator (instead of the players) to send commands to the lanes.

Mask Color

Not available with Frameworx

Opens a window where the color of the mask can be selected.

If the Color Sequencing Lane Option is enabled, the selected mask will be shown only for the first game. The mask of the following color will be shown for the second game and so on for each following game.

If the Color Sequencing Lane Option is not enabled, the selected mask color will always be used.

Monitor On/Off

Not available with Frameworx

Press to turn lane monitors on or off.

New Game Button

Not available with Frameworx

Enables the button on the lane that allows the start of a new game.

It can be pressed on the lane keyboard or Keyboard plugin.

It is only possible to proceed for operators with the Reset Lane through Special Functions privilege.

Reboot

Not available with Frameworx

Press to restart the lanes saving information.

Reopen

Reopens the lane with the same settings (options and players) of the last bowling session (the games played will be put together with those played previously).

Example: the game has finished, the lane is closed but the players change their minds and wish to continue playing.

Reset Lane

This function allows to restart the lanes deleting all the information regarding games, players, etc.

Restart Bumpers

Frameworx Only

Allows the front desk operator to restart bumpers on the selected lanes.

Reverse Arrow

Not available with Frameworx

Names are not moved from one monitor to the other when swapping and opening lanes in Alternate mode (Swap Lanes). In this case arrows will appear next to the names of the players that are changing direction at the moment of swapping.

This option is used when opening lanes, if the foreseen direction has to be inverted.

Split/Merge

Divide a pair of lanes into two single lanes by selecting the pair and pressing the Split button.

Join a single lane with its sister lane (if compatible) by selecting it and clicking on Merge .

These functions are unavailable if lanes are opened in Time mode with the Charge Double Time option checked in Center Setup.

Start New Game

Not available with Frameworx

Press to start a new game.

Touchscreen

Frameworx Only

Allows to enable and disable the touchscreen function on-lane, if monitors support it.

TV

A window displaying normal TV remote control options is available by pressing this button.

With BOSS it is also possible to choose if the Score has to be displayed on the Left , Right or on Both Monitors .

With AccuScore it is possible to choose the Double Grid option.

Other details are provided for each type of TV in the Technical Manual.

Send Password

Frameworx Only

Allows sending the password to the lanes, in order to access the on-lane maintenance menu.

The password has to be previously configured in the Center Setup.
