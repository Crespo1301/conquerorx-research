22. Lane Options - AS 80/90

Lane Printer

Enable the score printer if present on lanes.

Speaker

Activates the speaker in the overhead monitor, disabled by default.

Fill in Frames

Select to display the score after each bowl. If disabled, the score is displayed as usual, after the second bowl when the frame is complete.

Graphics

Displays special graphics for Strike , Spare , etc. on lane monitors.

Accumulated Score

In the case of League Extensions it is possible to have the cumulative score of previous games together with the current game score, which adapts accordingly as the game progresses. Available only on overhead monitor.

Mark Total Pinfall

In the case of League Extensions, the team Strike total, instead of the team total, is displayed in the score grid. Not available for Open play.

Print Score after Closure

Enable this option if the scores are to be printed automatically upon lane closure.

When opening lanes in the case of a tournament squad or a league week, a message warns that this option is enabled, so the operator can choose to confirm the printout or to disable it in order to save paper.

The score sheets are printed by the printer specified in the Terminal Setup.

High Game Exciter

Choose the minimum final score for which to have a graphic displayed on the lane monitor.

Console Language

During lane opening, choose between English or Spanish language to be used on lanes.

Overhead Monitor

Choose between Normal , Single and Double mode.

Classic Games

This option allows to set one of the Classic Games.

  • 3-6-9 : the 3rd, 6th and 9th frames are not played because three Strikes are automatically assigned to players.
  • No Tap : if the first bowl in the frame scores 8 or more (8 Pin No Tap ) or 9 or more (9 Pin No Tap ), it is automatically converted into a Strike.

Swap Lanes

Available configurations:

  • after every frame: Alternating
  • never: No Alternating
  • League Extensions : the differences from the normal alternating are:
    • bowlers can erase frames
    • it is possible to send practice, that means bowl without an arrow, so scores are not kept
    • the maximum number of bowlers on the lane is 8.

Display Type

It is possible to choose how to display the score on the lanes between Normal and Four Frame Grid .

Score Color Sequence

This option allows the operator to change the color of the grid and of the whole background of the screen at the beginning of each game. Choose a color set for the first game, the second game and the third game. After the third game, the color sequence restarts with the first color set.

Practice

In the case of an "alternating" league, practice can be:

  • On with Pins
  • On without Pins
  • Off

Practice Time

Set league practice duration in minutes.
