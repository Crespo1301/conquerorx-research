23. Lane Options - Frameworx

Professional Display

Allows to change the grid display into a more professional look; an additional row displays a symbol for each strike, spare etc.

Sound for Graphics

Enable sounds for graphics on the lane monitors.

Accumulated Score

In the case of League Extensions it is possible to have the cumulative score of previous games together with the current game score, which adapts accordingly as the game progresses. Available only on overhead monitor.

String of Strikes

By checking this option, if consecutive Strikes have been achieved, the score of each Strike is displayed on the grid after the next two bowls. If this option remains unchecked, consecutive Strike scores are displayed together as soon a non-strike bowl has been performed.

No Tap

If the first bowl in the frame scores 7 or more, 8 or more or 9 or more (according to the settings), it is converted to a Strike. Choose a value from 3 to 9.

Allow Editing No Tap

Allows the players to modify the values for the No Tap.

Bonus Frames

Choose 3 frames which will not played: 3 Strikes will automatically be assigned to players.

Allow Editing Bonus frames

Allows the players to modify the values for the Bonus Frames.

Allow Changing Bumpers

Allows the activation and deactivation of the bumpers for each single player.

Bumpers for All Players

Activates bumpers for the lanes.

Coach Control

Enables a fixed image on the monitors that shows the throw to be done in order to drop down the pins still standing.

Set the number of seconds the picture has to be displayed.

Swap Lanes

Available configurations:

  • after every frame: Alternating
  • never: No Alternating
  • League Extensions : the differences from the normal alternating are:
    • bowlers can erase frames
    • it is possible to send practice, that means bowl without an arrow, so scores are not kept
    • the maximum number of bowlers on the lane is 8.

Frames per Player

This setting defines the number of frames each player has to play before another player's turn. The possibilities are: 1 frame, 2 frames, 5 frames, 10 frames.

Frames per Lane

In League Mode or Alternating , this setting defines the number of frames each player has to play before changing lane. The possibilities are: 1 frame, 2 frames, 5 frames, 10 frames.

Special Game

Choose to enable a Special Game, between Monte Carlo , Poker and Color Head Pin .

Practice

In the case of a league mode, practice can be: On with Pins , On without Pins , Off .

Practice Time

Set league practice duration in minutes.

Sequencer Color Bar

The current player is highlighted with a different color.

Sequencer Arrows

The current player is highlighted with an arrow.

Recaps

In league mode, the league recap is displayed on the lane monitors.

Bowler Statistics

Displays the player statistics on the lane monitors.

Allow Viewing Previous Game

The bowler can view the grid of the previous game.

Auto-advertising

Enable the display of the advertising pictures.

Print Score after Closure

Enable this option if the scores are to be printed automatically upon lane closure.

When opening lanes in the case of a tournament squad or a league week, a message warns that this option is enabled, so the operator can choose to confirm the printout or to disable it in order to save paper.

The score sheets are printed by the printer specified in the Terminal Setup.

Frames per Row

  • Overhead Display

Choose between Normal, 4 frame grid, 5 frame grid and 7 frame grid.

  • Console Display

Choose between Normal, 4 frame grid, 5 frame grid and 7 frame grid.

High Game Exciter

Choose the minimum final score for which to have a graphic displayed on the lane monitor.

Console Language

During lane opening, choose the language to be used on lanes.

Score Color Sequence

Allows to have the color of the grid and of the whole background of the screen changing at the beginning of each game. Choose a color set for the first game, the second game and the third game. After the third game, the color sequence restarts with the first color set.

Walk Down Time

Set the amount of time it usually takes for bowlers from the moment their lane is opened at the front desk, to when they are present and ready for play on the lanes.

For example if a lane is opened for a group at 3:30 pm for an hour's play, and Walk Down Time is set at 2 minutes, the hour of play will commence at 3:32 pm.

Graphics

Displays special graphics for Strike, Spare, etc. on lane monitors.
