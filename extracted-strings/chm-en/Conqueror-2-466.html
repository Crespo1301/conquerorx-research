2. Devices

Select the devices connected to the terminal in the drop down menus:

Card Reader

Select the specific model and specify the port to which it is connected.

Drawer

Select the specific model and specify the port to which it is connected.

Display

Select the specific model, specify the port to which it is connected, enter the number of seconds after which the display of the last transaction is to be cleared and type a customized Welcome Message for the pole display connected to the terminal in use. It can be written on one or two rows, depending on the pole display model.

Beverage Dispenser

Select the specific model and specify the port to which it is connected.

Fingerprint Sensor

Select the specific model and specify the port to which it is connected.

PinPad

Configure the PINPad device as described in the Technical Documentation provided.

  • Note that First Data and Verifone, which use net devices, allow to share a single PINpad device between two or more terminals.

TERMINAL SETUP > Devices
