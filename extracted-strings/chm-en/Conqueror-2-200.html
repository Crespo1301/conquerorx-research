11. Management of Historical Games

Back Office > FBT > Historical Games

The Historical Games module allows to filter, display, modify, add and delete FB games present in the Historical Database.

Filtering Games

One or more games can be selected in order to analyze them in the main screen:

Insert the time range by completing the From Date and To Date fields.

To select a specific member's games, insert the FB ID , filling in the Frequent Bowler field.

Choose the Game Eligibility option desired and then select the Open, League and/or Tournament option.

Press Search to consult all filtered data in the main screen, complete with their opening mode, lane number, play date, opening and closing time.

To filter again from zero, press Clear .

Adding a New Game

Games can be added, one by one.

It is possible to choose to locate it into an existing event, or to create a new one:

  • To locate the new game into an existing event, click on the relevant event, press New Game , choose the specific event option, select the relevant FB, enter the game details (including the Game Number ) and press Save : the new game is automatically added in the Historical Database .
  • To create a new event with the new game being added, press New Game , choose the New Event option, select the relevant FB, enter the game details (including the Game Number ) and press Save : the new event/game is automatically created/added in the Historical Database .

Changing Eligibility Option

Select a game and press Eligibility to access and modify the Eligibility options of the game selected.

Modifying a Game

Click on the game to be modified and press Modify Game : the Game Details panel opens and the game details can be modified and saved.

It is possible to modify only the games present in the Historical Database ; games not modifiable are displayed in red and italic font.

Game statistics included in the FB reports, performable from the Filters and Reports module are modified accordingly.

Deleting a Game

Select the game to be deleted and press Delete Game .

This procedure is definitive and irreversible.
