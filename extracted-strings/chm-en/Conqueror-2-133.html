25. Virtual Waiter and Video Intercom Setup

Setup > Bowling Setup > Virtual Waiter

Virtual Waiter allows customers to order F&B very comfortably, as if a real waiter was always on the lane, at their disposal. The system provides menus right on the lane through the SuperTouch device and allows the customer to order by making a video call. Bowling Center staff can also video call the lane console screen proactively, to see if the customers need anything.

When a bowler makes a call from the SuperTouch a little Lane Calling dialog appears on Conqueror. As in a standard phone call, the operator can either accept or reject the lane call. When the operator clicks on the Accept button, the Video Call window appears automatically. If the operator misses a call, the Virtual Waiter Quick Button lights up - when the operator clicks on it the Video Call window opens automatically, allowing the operator to call the bowler back.

Menu File Management

Press Open to choose the Menu file to be displayed on the SuperTouch; then press Apply to send it to the consoles.

Terminal Settings

In the Terminals tab it is possible to set each terminal for Virtual Waiter and Video Intercom calls, associating them to specific lanes.

Assign a lane set to each terminal, and set them for Virtual Waiter calls, for Video Intercom calls, for both (All ) or for None .

Press Apply when the setup is complete.

Missed Calls Button

To have the Virtual Waiter Quick Button enable it is necessary to choose it under Setup > Terminal Setup > Quick Buttons.
