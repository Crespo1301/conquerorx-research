1.4 Score Sessions

Setup present only for the RDB hardware, and with BES, Bowland, Bowland-X and AS+.

The MMS screens can display the lane scores in real time.

In the Monitors tab, choose for the MMS screen between the 2-lane-display or the 4-lane-display. Then, choose which lanes to consider by setting the Lanes field appearing.

Every session can be different, with specific display options. Press Add to create a score session and in the window that opens, attribute a name to that score session.

If choosing the 2-lane-display, the player statistics of the two lanes selected will be shown.

With the Carry over Game Total it is possible to have the cumulative score of previous games together with the current game score which adapts accordingly as the game progresses.

Set the Display Game Total with Handicap if the handicap is to be added to the total game score, and choose if the score line is to contain:

  • the total only,
  • team's scratch, handicap, bonus and total,
  • no additional information.
