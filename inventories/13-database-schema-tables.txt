  C:\QDesk\Bin\ConquerorServer\SqlScripts\

File-prefix convention:
  a*    application procs / funcs / views (base)
  cs*   Create Structure (base tables) — cs0000 is v2.2.0.0 baseline
  cd*   Create Data (seed rows)
  cu*   Create Upgrade (versioned migration steps, e.g. cu02020600 = 2.20.06)
  cusp* Create User Stored Procedures
  cuz*  Create Upgrade (later series, contains many stored procs and funcs)
  hs*   Help/history support scripts
  ts*   Trigger/timing scripts
  luz*  Legacy upgrade zone
